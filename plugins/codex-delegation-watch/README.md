# Codex Delegation Watch

Надзор за делегированными тредами Codex в BB: у ребёнка поставлена цель (Goal),
работа идёт, о проблемах узнаёт родитель.

## Что делает

- Подключает каждый новый видимый тред Codex с родителем (можно выключить).
- Первая проверка через 2 мин (не позже интервала), затем по интервалу (5 мин).
- Нет цели после 90 с работы — просит ребёнка вызвать `create_goal`.
- Ход остановился при активной цели на двух проверках подряд — просит продолжить.
- Вопрос/разрешение, ошибка без повтора, цель blocked/paused/лимит, 15 мин без
  событий, ход закончен без цели — одно сообщение родителю `[Надзор Codex] …`.
- Подталкиваний не больше заданного максимума; дальше — сообщение родителю и
  режим наблюдения.
- Снимает надзор, когда цель `complete`, тред в архиве/удалён или прошло 3 дня.
- Тред без родителя только наблюдается.

## Настройки

Settings → Installed plugins → Codex Delegation Watch
(`/settings/plugins/codex-delegation-watch`) или `bb codex-watch config`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | Надзор включён. Выключение только останавливает проверки и подталкивания; треды работают как обычно, список сохраняется. После включения все открытые треды проверяются заново с первого шага. |
| `autoEnroll` | `true` | Подключать новые Codex-треды с родителем автоматически. |
| `defaultMode` | `supervise` | `supervise` — надзор с подталкиванием; `observe` — только наблюдать и сообщать родителю. |
| `intervalMinutes` | `5` | Интервал проверки, 1–60 мин. |
| `maxNudges` | `3` | Максимум подталкиваний на тред, 0–10 (0 — не подталкивать). |
| `checkGoal` | `true` | Проверять постановку цели. Выключено — тред без цели не подталкивается, но зависания и вопросы по-прежнему сообщаются. |

Под формой — список тредов под надзором: статус, последняя проверка,
подталкивания и кнопки «Проверить сейчас», «Только наблюдать» / «Надзор с
подталкиванием», «Снять с надзора». При выключенном надзоре «Проверить сейчас»
только показывает итог, ничего не отправляя.

## Команды

```
bb codex-watch status [--all] [--json]
bb codex-watch check <тред> [--json]          # без действий
bb codex-watch add <тред> [--observe|--supervise]
bb codex-watch mode <тред> supervise|observe
bb codex-watch remove <тред>
bb codex-watch resume-goal <тред>             # /goal resume для неработающего треда
bb codex-watch config get [ключ] [--json]
bb codex-watch config set <ключ> <значение>
```

Выключить: `bb codex-watch config set enabled false` или переключатель
«Надзор включён». Полностью удалить: `bb plugin remove codex-delegation-watch`.

## Разработка

`npm ci --include=dev`, `npm test`, `npm run typecheck`, `bb plugin build .`,
`bb plugin reload codex-delegation-watch`. Правила — `policy.ts` (тесты в
`policy.test.ts`), события, проверки и CLI — `server.ts`, экран — `app.tsx`,
RPC экрана — `contract.ts`.
