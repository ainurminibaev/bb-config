# Low Priority

Mark a thread low priority: new turns in it and its subthreads wait while the
5-hour or weekly subscription limit is at or above the thread's percent, and
go out by themselves afterwards. Toggle from the composer's `+` menu or with
`bb low-priority on|off|status|list`. Details: `skills/low-priority/SKILL.md`.

```bash
npm ci && npm run typecheck && npm test
bb plugin build && bb plugin install . --yes
```
