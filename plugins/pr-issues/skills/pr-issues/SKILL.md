# PR и Issues

Плагин `pr-issues` добавляет в боковое меню BB страницу «PR и Issues».

## Что попадает на страницу

Сервер BB раз в 10 минут (и по кнопке «Обновить») ищет через свой `gh`:

- все PR и issue, которые пользователь создал на GitHub (в любых репозиториях);
- открытые запросы ревью от пользователя;
- записи, где пользователь участвовал (упоминание, комментарий) за 30 дней;
- открытые и закрытые за 30 дней записи в репозиториях проектов BB
  (по `gitRemoteUrl` проекта) и в «Дополнительных репозиториях» из настроек.

Токен плагин не хранит: используется логин `gh` на сервере BB
(`gh auth status`).

## Разделы

- **Нужно ваше действие** — ответили после вашего последнего действия; просят
  изменения; конфликт; упали проверки; одобрено и вы можете влить; просят
  ваше ревью; новый PR/issue от другого человека в репозитории, куда у вас
  есть запись.
- **Ждут других** — открытые, ход не за вами.
- **Завершённые** — влиты, закрыты, а также скрытые вами («Скрыть до нового
  ответа»: запись вернётся, когда кто-то напишет).
- **Лента изменений** — смены статусов, новые ответы, новые записи.

Точка «новое» — с прошлого просмотра сменился статус или ответил другой
человек; снимается при открытии записи. Боты не считаются ответом.

## Команды

```sh
bb prs list                    # что ждёт действия пользователя
bb prs list --bucket all --json
bb prs refresh                 # обновить сейчас и дождаться
```

Действия на странице (комментарий, закрыть, открыть заново, влить squash,
одобрить) выполняются от имени пользователя только по клику с подтверждением.
«Новый тред» создаёт тред в выбранном проекте BB с поручением разобраться
и ничего не отправлять на GitHub без подтверждения. Агент сам эти действия
на GitHub без явной просьбы пользователя не выполняет.

## Диагностика

- «Не удалось обновить» — выполните на сервере BB `gh auth status`.
- Часть поиска не удалась — обычно удалённый или недоступный репозиторий
  проекта; добавьте его в «Не показывать репозитории».
- Данные: хранилище плагина (`state`, `seen`, `mutes`, `events`).
