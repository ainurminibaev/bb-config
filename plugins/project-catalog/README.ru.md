# Project Catalog

Вкладка **Проекты** и команда `bb catalog`: одна общая карточка на каждый
проект BB (описание, ваши заметки, категория, теги, псевдонимы, ссылки, статус)
и состояние папок проекта на каждой машине.

BB хранит у проекта только имя, git remote и папки и ищет проект по имени.
Каталог лежит в хранилище плагина на сервере BB, поэтому все машины, агенты и
вкладка видят одни и те же карточки.

- **Вкладка**: поиск (русское написание находит латинское имя), категории,
  фильтры по машине и состоянию, карточки по категориям, страница карточки с
  правкой на месте, состоянием по машинам и списком различающихся файлов.
- **Категории**: до четырёх у проекта, группы категорий в боковой панели,
  переименование и удаление на месте.
- **Быстрые действия** в строке: последние треды проекта, правка, новый тред.
- **Клавиатура**: `/` поиск, `↑`/`↓` по списку, `N` новый тред, `Esc` закрыть.
- **CLI для агентов**: `bb catalog find|list|show|describe|set|unlock|categories|group|sync`,
  краткий вывод или `--json`; подробности — `skills/project-catalog/SKILL.md`.
- **Автоописание**: тред проекта без карточки (или с устаревшей) один раз
  просят выполнить `bb catalog describe`; плагин сам модель не вызывает.
- **Ручные правки сохраняются**: поле, изменённое во вкладке или через
  `bb catalog set`, автоописание не трогает; заметки не пишутся автоматически.

Нужен Machine Tabs для показа проекта в боковой панели. Установка — в наборе
bb-config (`python3 scripts/updates.py apply`); подробности на английском — в
[README.md](README.md).
