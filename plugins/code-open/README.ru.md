# Code Open

Просмотр кода в один клик. Плагин добавляет кнопку `</>` в заголовки проектов,
строки тредов и заголовок открытого треда. Нажатие открывает редактор
[KodaForge](https://github.com/Kodaks94/bb-plugin-kodaforge) в нужной рабочей
области на нужной машине: справа открыт чат, список тредов BB свёрнут — экран
читается как «файлы · код · чат».

Своего редактора нет, нужен плагин `kodaforge` (входит в набор bb-config).
Подробности и обслуживание — `skills/code-open/SKILL.md`.
