# Code Open

One-click code view for BB. Adds a `</>` button to project headers, thread rows
and the open thread's header. A click opens the [KodaForge](https://github.com/Kodaks94/bb-plugin-kodaforge)
editor at the right workspace on the right machine, with the chat panel open on
the right and BB's thread list collapsed, so the screen reads files · code · chat.

The project button opens the default project checkout. Both thread buttons open that thread’s environment.

It has no editor of its own and requires the `kodaforge` plugin. Details and
maintenance notes are in `skills/code-open/SKILL.md`.
