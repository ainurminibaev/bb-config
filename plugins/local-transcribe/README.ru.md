# Local Transcribe

Расшифровка аудио и видео со спикерами и таймкодами на ваших машинах через
исполнители BB: сначала Mac с GPU, затем готовые запасные машины по политике
вызова. Агент проекта затем готовит итоги, решения, задачи и PDF. В облачный
сервис распознавания ничего не уходит, если вы сами его не выбрали.

- **Обновления**: Python-движок входит в host-пакет плагина; после одного
  обновления в BB исполнители получают версионированный код при обращении,
  окружения готовятся автоматически. Запущенные задачи сохраняют свой каталог;
  веса моделей и результаты остаются.
- **Уведомления**: задача с ID треда один раз будит этот тред результатом или ошибкой.
- **Требования**: подключённые машины macOS/Linux с Python 3.10+ и ffmpeg; для
  новых окружений и моделей нужен доступ к публичным репозиториям пакетов и
  весов. Номера спикеров — не личности: имена людей требуют проверки.

Настройки: `workerHosts` (ID машин-исполнителей, хранятся приватно), `autoSetup`.
Проверка: `bb plugin rpc call local-transcribe services --json`.

Входит в набор [bb-config](../../README.ru.md): `python3 scripts/updates.py apply` из корня репозитория ставит его вместе с остальным. Рабочая установка может идти из собственного Git-источника — набор его
сохраняет. Отдельно: `npm ci --ignore-scripts`, `bb plugin build .`,
`bb plugin install . --yes`. Описание для каталога — `PLUGIN_OVERVIEW.md`.
