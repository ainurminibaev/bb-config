---
name: kodaforge-inspector
description: Проверка центрального чата KodaForge, источника обновлений и возврат к штатному расположению панелей.
---

При запросе о центральном чате проверь `bb kodaforge-inspector status`. Сопоставь время последней проверки браузера с последним открытием редактора. Для свежего результата открой KodaForge для диалога и проверь статус ещё раз. Причина несовместимости указана в поле `browser.reason`.

Вид выбирается по проектам: «Применить» в окне выбора сохраняет его для проекта открытого диалога, «Сохранить для всех» — в общую настройку со сбросом выбора проектов; выбор проекта важнее общего. `status` показывает общее значение и число проектов с собственным выбором (`projectChoices`). Общий вид хранится в настройке `layout`: `ask` (по умолчанию; при открытии редактора диалога показывается окно выбора с примерами, до выбора вид штатный), `native` (штатный: код по центру, чат справа) и `center` (чат по центру). По запросу «вернуть штатный KodaForge» выполни `bb plugin config kodaforge-inspector set layout native`; для центрального чата — `center`; чтобы окно выбора появилось снова — `ask`. Не выбирай вид за пользователя без просьбы. Полное отключение слоя — `bb plugin disable kodaforge-inspector`.

Настройки `autoOpen` (по умолчанию выключено) и `autoOpenThread` (ID диалога `thr_…`) перенаправляют обычную страницу одного выбранного диалога сразу в KodaForge; ссылки на сообщения и прочие диалоги не затрагиваются. Включай и меняй ID только по просьбе пользователя: `bb plugin config kodaforge-inspector set autoOpen true`, `… set autoOpenThread <id>`.

Источник основной установки смотри через `bb plugin source kodaforge --json`. Для обновления основного плагина по запросу пользователя используй штатный механизм BB. Инструкция по установке и проверке находится в README плагина.

The view chooser opens by «Вид…» in the toolbar (center) or in KodaForge's title bar (classic, postponed choice). Without the title bar slot use the plugin's `layout` setting.
