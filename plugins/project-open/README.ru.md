# Project Open

Два значка — «папка» и «терминал» — в строках и заголовках тредов. В боковой
панели они видны при наведении или фокусе, в заголовке — всегда. Подсказка
через 100 мс показывает действие, машину и полный путь окружения треда.
Штатные кнопки и меню BB сохраняются.

Настройка `placement`: `row` (по умолчанию) — значки в строках; `menu` — действия
в штатном меню **…** треда, откуда их можно закрепить через **Customize actions**.
Переключение: `bb plugin config project-open set placement menu`.

Терминал открывается штатным BB (New tab → Start terminal) в панели треда или на
машине проекта; своего терминала и SSH-интерфейса нет.

## Finder на macOS

Необязательное локальное приложение `BB Project Folder.app` обрабатывает ссылки
`bb-project-folder://`. Локальный проект открывается в Finder сразу, удалённый
подключается уже установленным rclone через существующий профиль OpenSSH по
WebDAV на loopback; диск подключает штатный `mount_webdav`. Не нужны FUSE,
сетевые шары, копирование ключей и новая авторизация на сервере. Обработчик
принимает только настроенные машины и разрешённые корни проектов; настройки
лежат в `~/Library/Application Support/BB Project Folder/` на вашем Mac.

Установка обработчика на Mac (`macos/install.py`) и формат настроек — в
[README.md](README.md). Сам плагин входит в набор bb-config
(`python3 scripts/updates.py apply`).

В дереве KodaForge (из форка с точкой `kodaforge:explorer-menu`) плагин добавляет пункт «Открыть в Finder»: папка открывается сама, файл — своей папкой. Нужен Mac и включённый `finderHelper`.
