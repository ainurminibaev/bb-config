# Thread Description

```sh
bb thread-description show --thread <id>      # описание, сводка, модель, ошибка
bb thread-description refresh --thread <id>   # обновить сейчас (до 3 минут на модель)
bb thread-description set --thread <id> --text "…"   # ручное описание; пустой текст возвращает авто
bb thread-description models --thread <id>    # какая модель и машина будут использованы
```

Ручное описание ставь только по просьбе пользователя: автоматика его больше не меняет.

## Когда обновляется

1. Тред или подтред начал работу, описания нет — по первой задаче.
2. Первая задача короче `shortWords` (15) слов — ещё раз после первого ответа агента.
3. Прошло `refreshMinutes` (60), есть новые сообщения и тред затих.

Скрытые и архивные треды не описываются; подтреды выключает `subthreads`, всё автоматическое — `enabled`.
Старые треды получают описание при следующей активности. После ошибки пауза 10 минут, циклов повтора нет.

## Выбор модели

Машина исходного треда: провайдер и модель из настроек → небольшая модель того же провайдера →
другой доступный провайдер. Если на машине нет ни одного — машина `fallbackHostId`.
Нет и её — ошибка «Нет доступной модели» в карточке иконки. Аккаунт выбирает BB, как для любого треда.

Генерирует скрытый тред в личной папке машины (без инструкций проекта и файлов пользователя);
после ответа он удаляется, оставшиеся после перезапуска удаляются при загрузке плагина.

## Диагностика

- Нет иконки: BB изменил разметку шапки (опора — `data-thread-header-workflow-actions` и кнопка `Thread actions`, `title-anchor.ts`). Команды и кнопка у поля ввода работают и без неё.
- На узком экране кнопки у поля ввода нет (BB не показывает там действия плагинов); сводка есть в карточке иконки.
- `bb plugin logs thread-description` — причины неудачных генераций.
