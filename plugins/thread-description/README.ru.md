# Thread Description

Короткое описание и сводка для каждого треда и подтреда BB.

- **Иконка у названия треда** — о чём тред. Наведение или клик: описание, сводка, «Обновить», «Изменить».
- **Кнопка у поля ввода** — сводка «где мы сейчас и что дальше» над полем ввода; по умолчанию свёрнута, состояние общее для всех устройств, точка означает новую сводку.

Описание создаётся по первой задаче; если она короче 15 слов — дописывается после
первого ответа агента; дальше обновляется не чаще раза в час, когда в треде были
новые сообщения и он затих. Исправленное вручную описание автоматика не трогает.

Текст пишет скрытый служебный тред BB на машине исходного треда, в пустой личной
папке. В контекст вашего треда ничего не попадает. Модель — из настроек (Claude
Haiku), нет её — другая доступная на машине. Каждая генерация — обычный запрос
к провайдеру и расходует его лимит; фрагменты переписки уходят этому провайдеру.

Как выбирается модель, настройки и диагностика: `skills/thread-description/SKILL.md`.

```bash
npm ci && npm run typecheck && npm test
bb plugin build . && bb plugin install .
```
