# Plugin Keeper (id `voice-mode-keeper`)

Сохраняет ваши исправления плагинов из каталога при их обновлениях: Needs You
(`inbox`), Tokenomics и KodaForge. Форков не создаёт.

Каждые 10 минут, после запуска и после обновления плагина Keeper проверяет
установленную версию. Новую версию он проверяет в отдельной копии: накладывает
правки (с допуском на сдвиги и переформатирование), запускает тесты, TypeScript и
сборку, затем перезагружает плагин. Если правка не подходит или проверка не
проходит, остаётся оригинальная версия, а настройки плагина показывают
предупреждение. Учётные данные не читаются и не копируются; отключённый плагин
не включается. После успешного сохранения обновляется приватный снимок bb-config.

Это проверяемый слой совместимости, а не гарантия для любой будущей версии.
Тесты: `python3 plugins/voice-mode-keeper/test_patch_keeper.py`.
Установка — в наборе bb-config (`python3 scripts/updates.py apply`); рядом
должны оставаться каталоги патчей (`plugins/inbox-compat`,
`plugins/kodaforge-compat`; исправление Tokenomics — `tokenomics_compat.py` внутри Keeper). Подробности — [README.md](README.md).
