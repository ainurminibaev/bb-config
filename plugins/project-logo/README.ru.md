# Project Logo

Автоматически даёт каждому проекту BB компактный значок в боковой панели. В
начале треда агент проверяет значок проекта; если его нет, подбирает по
названию проекта и первому сообщению: собственный знак проекта, подлинную
официальную эмблему, когда проект явно о ней, или простой монохромный SVG,
нарисованный для проекта. Существующие значки не заменяются.

Значок сохраняется как `.bb/icon.svg` или `.bb/icon.png` (до 256 КБ) в корне
проекта на машине, где лежит его исходник, и обновляет Machine Tabs. Он общий для
проекта и всех его тредов. Ничего не коммитится и не пушится. Инструменты для
агентов: `project_logo_status`, `project_logo_install`.

Для показа значков нужен [Machine Tabs](../machine-tabs). Входит в набор [bb-config](../../README.ru.md): `python3 scripts/updates.py apply` из корня репозитория ставит его вместе с остальным.
Проверки: `npm test`, `npm run typecheck`.
