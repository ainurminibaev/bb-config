# Machine Tabs (id `machine-tabs`)

Штатный список тредов BB с рядом вкладок машин над ним: выберите машину — и
видны только её треды, а группировка, сортировка и меню BB остаются прежними.

- **Вкладки машин** со счётчиками; выбранная вкладка хранится на сервере и
  синхронизируется между окнами.
- **Двухуровневая группировка**: Group by / Then by (проект, машина, день, без
  группировки) и сортировка (обновление, создание, имя). Группы проектов идут по
  последней активности.
- **Поиск** по названиям тредов и заголовкам групп без учёта регистра, неверной
  раскладки RU/EN и алфавита («маруся» находит `marusya`).
- **Фильтры** по теме и проекту со счётчиками («7 из 24») вместе с вкладкой и поиском.
- **Last 5**: пять последних обновлённых тредов сверху; дочерние треды,
  раскрытие и индикаторы активности работают.
- **Значки проектов** перед названием: картинка проекта или две буквы. Значок —
  файл `.bb/icon.svg` или `.bb/icon.png` в корне проекта, затем
  `bb machine-tabs icons`.

Включение: Settings → Appearance → Sidebar: «Thread list + machine tabs».
CLI: `bb machine-tabs list`, `bb machine-tabs select <id машины|all>`,
`bb machine-tabs icons`. Значок перед названием — настройка `rowMark`
(`ask`, `project`, `topic`). Инструкция для агентов — `skills/machine-tabs/SKILL.md`.

Плагин оборачивает встроенный список тредов BB и зависит от его разметки: после
обновления BB может понадобиться обновить и его.

## Установка

Входит в набор bb-config: `python3 scripts/updates.py apply` из корня
репозитория ставит его вместе с остальным. Отдельно:

```sh
npm --prefix plugins/machine-tabs ci --include=dev
bb plugin build plugins/machine-tabs
bb plugin install path:"$PWD/plugins/machine-tabs"
```

Проверки: `npm run typecheck`, `npm test`.
