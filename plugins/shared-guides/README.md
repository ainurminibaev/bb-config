# Shared Guides

Skills-only plugin. Global Custom instructions in BB keep only short triggers
("when and what"); the procedures ("how") live here and load on demand.

| Skill | Trigger block in Custom instructions |
|---|---|
| bb-config-tracking | `[bb-config tracking]` |
| thread-transfer | `[thread transfer]` |
| project-logos | `[project logos]` |
| agent-compat | `[agent compatibility]` |

No server, UI, tools or settings. Install: `bb plugin install path:<checkout>/plugins/shared-guides --yes`.
