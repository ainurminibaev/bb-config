# Значок проекта в BB

- «Логотип треду/сессии/проекту», «иконка рядом с названием» — это общий значок
  проекта и всех его тредов в боковой панели (machine-tabs). Отдельного значка
  у одного треда нет; если нужен именно он — уточни поведение.
- Проект, корень и машину бери из BB: `bb status --json`,
  `bb project show <id> --json` (`sources[].path`, `hostId`). Не угадывай
  домашний каталог macOS или `/root`, не бери cwd другого проекта.
- Обычный путь — плагин Project Logo: `bb project-logo status <project-id>`,
  `bb project-logo install <project-id> <относительный-путь> <source-url>`,
  `bb project-logo create <project-id> '<svg>'`. Существующий значок он не
  заменяет.
- Исходник: присланный пользователем файл или фирменный знак проекта; для
  своего проекта — простой оригинальный SVG без текста. Чужой бренд не
  выдумывай и не рисуй «похожим». Для маленькой иконки — знак без надписи;
  SVG оставляй векторным.
- Замена вручную: в корне источника на нужной машине `.bb/icon.svg` или
  `.bb/icon.png` (до 256 КБ). Приоритет: `.bb/icon.png`, `.bb/icon.svg`,
  `favicon.png`, `favicon.svg`, `favicon.ico` — проверь более приоритетные
  файлы, без необходимости не удаляй. Другая машина — `bb file`/`bb terminal`
  с явным `--host`/`--machine`.
- Проверка: `bb machine-tabs icons` — проект отмечен `*`. Плагин показывает
  значки серыми. Если machine-tabs не установлен — не ставь сам, сообщи.
- Проверь `git diff`; commit/push — только по запросу.
