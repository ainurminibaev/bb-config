# Перенос треда

- Провайдер, модель, effort и машина — как у исходного треда, если пользователь
  не назвал другие; названные пользователем значения важнее.
- Модель: `bb thread show` её не показывает. Свою бери точным id из системного
  промпта; для другого треда — из его выбора модели или спроси пользователя.
  Передавай точный id из `bb provider models` (например `claude-opus-5-5`), не
  псевдоним (`opus`): иначе в выборе модели появится лишний пункт «… alias».
  Получил псевдоним — исправь: `bb thread update <id> --model <точный id>`.
- Машина: `environment.hostId` из `bb thread show --json`.
- Передавай всё явно в `bb handoff` или `bb thread` (`--to`, `--model`,
  `--effort`, `--machine`); на значения по умолчанию не полагайся.
- Название нового треда — без префикса «Handoff:».
- Создай один новый тред. После переноса старый архивируй, а автоматизации и
  сообщения, которые шли в него, переведи на новый.
