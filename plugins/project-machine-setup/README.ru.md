# Project Machine Setup

Добавляет кнопку **Подключить проект** прямо перед неактивной кнопкой отправки,
когда поле нового треда сообщает **Select an environment.** Кнопка открывает
штатный экран BB **Environment → Set up on <машина>…**: там можно клонировать
репозиторий проекта или выбрать существующую папку. Сама кнопка не отправляет
черновик, не меняет машину, не копирует незакоммиченные файлы и ничего не
клонирует.

Работает в развёрнутом и компактном поле нового треда. Нет настроек, сервера,
учётных данных и хранилища; формы BB не дублируются. Опирается на разметку BB
0.49 (`data-app-composer`, `data-new-thread-footer`,
`data-promptbox-submit-action`) и английские подписи; при их изменении кнопка
просто не появляется, штатная настройка окружения остаётся.

## Установка и обновление

Входит в набор bb-config (`python3 scripts/updates.py apply`). Отдельно:

```sh
cd plugins/project-machine-setup
npm ci && npm test && npm run typecheck
bb plugin build .
bb plugin install .
```

Обновление локальной копии: сборка и `bb plugin reload project-machine-setup`.
Удаление: `bb plugin uninstall project-machine-setup`.

При клонировании на машину проверьте папку назначения. Git переносит только
закоммиченное: локальные правки, игнорируемые файлы, вложенные репозитории и
сессии внешних агентов переносятся отдельно.
