# Push Button

Компактная кнопка «Пуш» рядом со штатным баннером изменённых файлов, а без него —
после переключателя ветки в нижней строке треда. Нажатие отправляет в тред
обычное сообщение пользователя `пуш` через `sdk.threads.send`
(`queue-if-active`). Кнопка сама не запускает Git, не меняет права и не трогает
черновик: ревью, коммит и пуш агент делает как обычную просьбу.

Кнопка неактивна, пока статус Git загружается или отправлять нечего. Статус
читается только на чтение (`git status --porcelain=v2 --branch --ahead-behind`
в окружении треда, без fetch) и обновляется раз в 5 секунд, пока кнопка видна.
Распознаются изменённые и новые файлы, коммиты впереди upstream и первая
публикация ветки.

На телефонах кнопка остаётся подписанной, на сенсорных экранах до 640 px — 44 px
в высоту. Если в строке состояния нет штатного выбора проекта, первым
показывается название проекта. Отключение плагина убирает кнопку и
наблюдатель; штатные элементы BB не меняются. После обновлений интерфейса BB
разметку нужно перепроверять.

Установка: входит в набор bb-config (`python3 scripts/updates.py apply`);
отдельно — `npm ci`, `bb plugin build .`,
`bb plugin install path:<абсолютный-путь-к-плагину> --yes`.
Проверка: `npm run typecheck`, `npm test`.
