# Open on Desktop (id `file-local-open`)

Небольшой плагин-спутник BB: значки ноутбука и загрузки рядом со ссылками на
файлы в чате. Первый копирует файл с сервера в «Загрузки» вашего Mac или
Windows-компьютера и открывает его программой по умолчанию (на Mac HTML — в
Chrome), второй только сохраняет. Файл, который уже лежит на этом компьютере
(BB работает на одном ПК), открывается на месте без копии. Включает просмотр PDF
по ширине панели без боковой ленты миниатюр.

Исходники остаются на своей машине. «Сохранить» пишет прямо в `~/Downloads/`
(`имя (2).ext` при совпадении; HTML с файлами — в свою папку) и показывает файл
в Finder; «Открыть» использует новые папки в `~/Downloads/BB Files/`. Байты
сверяются по SHA-256. Без форка BB и встроенных плагинов: только поддерживаемые
API content-script, composer, file-opener и host RPC.

Ограничения и команды — [навык](skills/file-local-open/SKILL.md). При нескольких
настольных компьютерах задайте `macHostId` в настройках плагина.

Проверка: `npm ci`, `npm run typecheck`,
`node --experimental-strip-types --test files.test.mjs`, `bb plugin build .`.
