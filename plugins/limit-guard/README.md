# Limit Guard

Подсказывает агентам Claude Code и Codex, сколько осталось лимита подписки их
треда, и задаёт правила работы. Цель: работа не теряется, когда лимит
кончается посреди задачи, и её может подхватить другой агент.

## Что делает

- **Инструмент `limit_status`** для агента и команда
  `bb limit status [--thread <id>] [--refresh] [--json]` для людей и скриптов.
  Показывают окна лимита (5 часов, неделя, окно модели), процент, время до
  сброса и режим работы.
- **Режимы:**
  - обычный — меньше `economyPercent` (70 по умолчанию);
  - экономный — до `finishPercent` (90): маленькие шаги, после каждого коммит
    и push;
  - финиш — от `finishPercent`: ничего нового, сохранить и написать «что
    сделано / что дальше / как проверить»;
  - неизвестно — данных нет: маленькие сохраняемые шаги.
- **Правила в инструкциях сессии** (только Claude Code и Codex): когда
  проверять лимит, разрешение на коммит и push своих файлов в текущую ветку в
  экономном режиме и в финише, запрет force-push, чужих файлов и секретов. Как
  поступать при отклонённом push и в папке без git.

## Ограничения

- Цифры берутся из `sdk.system.usageLimits` машины, на которой работает тред.
  При пуле аккаунтов или отдельной авторизации треда они могут относиться к
  другому аккаунту; при включённом пуле вывод об этом предупреждает.
- Правила и инструмент попадают в сессию при её следующем запуске. Посреди хода
  агент узнаёт лимит, только вызвав `limit_status`.
- Плагин не останавливает ходы, ничего не коммитит сам и не переключает
  провайдера. Продолжение после сброса окна делает `provider-retry`, передачу
  другому агенту — `bb handoff`.

## Установка и обновление

```sh
cd plugins/limit-guard
npm ci
npm test
npm run typecheck
bb plugin build .
bb plugin install . --yes      # на сервере BB
```

Пороги: `bb plugin config limit-guard set economyPercent 70` и
`bb plugin config limit-guard set finishPercent 90`. После правки установленной
копии: `bb plugin build . && bb plugin reload limit-guard`. Удаление:
`bb plugin uninstall limit-guard`.

Проверка: `bb limit status --thread <id треда Claude или Codex>`.
