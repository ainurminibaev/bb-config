# Требования: работа не теряется, папки не разъезжаются, лимит бережётся

Сводка решений из обсуждений 19.11.2026: два треда (лимиты и синхронизация;
моды, подсказка и неприоритетный тред) и проектное и финальное ревью. Этот
файл — источник правды по теме. Новые требования дописываются сюда, а не
остаются в переписке.

Статусы: **сделано** — работает на сервере BB и покрыто тестами;
**требуется** — решено, но не сделано; **отложено** — решено не делать сейчас.

## 0. Принципы

1. **Без кнопок и ритуалов.** Пользователь работает как раньше, автоматика
   срабатывает сама. Настройки — значения по умолчанию в плагине, выключатель
   на случай ручной работы.
2. **Решает код, а не модель.** То, что должно произойти надёжно (сохранить
   работу, подтянуть папку, изолировать второй тред), делает плагин. Модели
   оставляется не больше одного явного шага.
3. **Не мешать ручной работе.** Автоматика не трогает рабочие файлы, ветку и
   индекс пользователя. Исключения — подтягивание чистой отставшей папки при
   старте треда и вливание закоммиченной работы из копии в свободную чистую
   папку.
4. **Ничего не терять и не публиковать без спроса.** Нет force-push, нет
   автокоммитов в рабочую ветку, наружу ничего не уходит по умолчанию,
   секреты не уходят никогда.
5. **Выключатели:** файл `.bb/hands-off` в папке; настройки плагинов;
   `bb plugin disable <id>`.
6. **Не перегружать интерфейс:** аккуратно, мелко, без цвета; новое — в
   существующие места (меню «+», шапка, боковой список).

Также: в финише агент должен доделать текущий шаг, а не останавливаться, ничего не сделав | сделано (0.6.0): инструмент `limit_resume_after_reset` и `bb limit resume`; строка очереди со временем сброса проверена вживую |
