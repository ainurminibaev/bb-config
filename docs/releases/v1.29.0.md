# v1.29.0 — Thread Account Usage 0.3.5: квота Codex видна там, где BB получает 403

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Thread Account Usage 0.3.5: квота Codex видна там, где BB получает 403** (машины в RU). Если
  `usageLimits` вернул для Codex ошибку, строка в «Все аккаунты» строится по ответу самого Codex
  на машине (`account/rateLimits/read`): процент и сброс недельного или пятичасового окна, тариф и
  почта. Запрос лимит не тратит.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `thread-account-usage-0-3-5` — Thread Account Usage 0.3.5 — квота Codex у самого Codex, когда usageLimits отвечает 403

Если BB не может прочитать квоту Codex на машине (в «Все аккаунты» — «Codex usage request failed (HTTP 403)», так бывает на машинах с российским IP), панель берёт квоту у самого Codex на этой машине: процент и сброс недельного окна, тариф и почту аккаунта. Запрос к Codex только читает данные и лимит не тратит. Хост-часть плагина обновляется вместе с ним; пока на машине работает прежняя, там видна прежняя ошибка.
Откат: тег thread-account-usage/v0.3.4.
