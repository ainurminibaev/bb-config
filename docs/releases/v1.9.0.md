# v1.9.0 — bb-config v1.9.0: Context Mode Rollout

## Что изменилось

- Новый плагин **Context Mode Rollout** (`context-mode-rollout` 0.4.0) держит
  расширение [context-mode](https://github.com/mksglu/context-mode) во всех
  агентах на всех машинах BB и ставит его на новые машины при подключении.
- Claude Code, Codex, Gemini CLI, Pi, OpenCode, Qwen, Copilot CLI — штатный
  `context-mode setup` (MCP и хуки), если CLI найден в PATH.
- Antigravity (CLI `agy` и приложение) и Cursor — только MCP-сервер в их
  пользовательском конфиге: context-mode не поддерживает их хуки. Чужие записи
  сохраняются, резервная копия — `*.before-context-mode`.
- Версия — актуальная стабильная с npm после 2 дней выдержки, по Node машины
  (`engines.node`). Неудачное обновление откатывается на прежнюю версию.
- Без sudo; аккаунты, авторизации и маршруты не меняются.

Общий порядок — [docs/updates.md](../updates.md).

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `plugin-context-mode-rollout` — Context Mode Rollout 0.4.0: актуальный context-mode во всех агентах на всех машинах BB, включая новые

Устанавливает на сервере BB новый плагин Context Mode Rollout 0.4.0. Штатный
шаг `local-plugin` собирает и ставит плагин из `plugins/context-mode-rollout`
и проверяет источник и версию.

Плагин держит актуальное расширение context-mode в Claude Code, Codex, Gemini
CLI, Pi и других агентах, которых поддерживает context-mode, а в Antigravity
(CLI и приложение) и Cursor подключает его MCP-сервер, на
каждой подключённой машине BB: новую машину проверяет сразу после подключения,
остальные — раз в сутки, новый релиз с npm (выдержанный 2 дня) раскатывает
сразу. Закрепить версию: `bb plugin config context-mode-rollout set version X.Y.Z`.
Версия выбирается по Node машины (`engines.node` из npm): если Node слишком
старый, плагин ничего не ставит и просит обновить Node. Если после обновления
проверка не прошла, плагин возвращает прежнюю версию и эту больше не пробует. Нет пакета — ставит его через npm без
sudo, затем запускает `context-mode setup` только для найденных CLI и
проверяет `context-mode doctor`. Если context-mode уже настроен, ничего не
меняет. Выключить: `bb plugin config context-mode-rollout set autoInstall false`.

Проверка: `bb context-mode-rollout status` — у каждой подключённой машины с
Claude Code или Codex состояние `ok` или `installed`; `bb context-mode-rollout
check` — сухой прогон без изменений.
