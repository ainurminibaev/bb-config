# v1.2.5 — Сортировка дочерних тредов в Machine Tabs

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

Дочерние треды из других проектов показываются в дереве родителя и в своём проекте. В своём проекте их строки участвуют в общей сортировке и счётчике. Меню и кнопки обеих строк действуют на ту же сессию.

## Шаги

### `plugin-machine-tabs-project-alias-paging` — Machine Tabs 0.2.3 — сортировка и счётчик строк проекта

Обновляет установленный Machine Tabs на сервере BB до 0.2.3. Шаг
`local-plugin` проверяет источник и версию, при необходимости собирает и
перезагружает плагин.

Дочерний тред из другого проекта открывается и из дерева родителя, и из
своего проекта. Строка в собственном проекте следует выбранной сортировке,
входит в общий счётчик и сворачивается вместе с остальными строками. Обе
строки используют штатные кнопки треда. Перетаскивание доступно в исходном
дереве.

Для проверки откройте группировку по проектам, разверните проект с
дополнительной строкой и сравните число строк со счётчиком. Переключите
Last updated и Name и проверьте порядок. Откройте одну
сессию из обоих мест и проверьте наличие штатного меню на обеих строках.

## Проверка релиза

- Манифест проверяется на коммите релиза в чистом клоне.
- Тесты Machine Tabs проверяют сортировку и счётчик списка с дополнительной строкой.
- Проверка рендера подтверждает общий размер страницы и доступность перетаскивания в исходной строке.
