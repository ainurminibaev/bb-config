# v1.2.3 — Machine Tabs восстанавливает список после запуска BB

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

Machine Tabs 0.2.2 автоматически восстанавливает список тредов в режиме
Custom после запуска BB. Пока встроенный Thread List загружается, панель
показывает ожидание и сама повторяет запрос.

## Шаги

### `plugin-machine-tabs-startup-recovery` — Machine Tabs 0.2.2 — автоматическая загрузка списка после запуска BB

После старта BB режим Custom автоматически дожидается встроенного Thread List
и показывает треды без перезагрузки страницы. Состояние ожидания видно в панели.
Если сам BB сообщает об отключении или сбое встроенного плагина, Machine Tabs
указывает, где проверить его состояние.

Шаг проверяет версию и источник установленного Machine Tabs. Для обновления
он собирает и перезагружает плагин из закреплённых исходников. Проверка:
`node --test plugins/machine-tabs/tests/thread-list-bundle.test.mjs`.

## Проверка релиза

- Тесты воспроизводят задержку загрузки Thread List и проверяют получение
  списка, обработку отключённого плагина и отмену ожидания при закрытии панели.
- Плагин собирается штатной командой `bb plugin build plugins/machine-tabs`.
