# v1.13.0 — Обновления 12 плагинов — штатно через BB (Git-источник); Push Button 0.1.1

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **12 плагинов bb-config получают обновления штатно от BB.** Subthread Autocollapse, Web BB Button, Handoff Button, Project Machine Setup, Shared Guides, Git Thread Provenance, Codex Goal Queue, Fresh Thread Hint, Project Open, Code Open, Thread Account Usage и Push Button переводятся с папки выпуска на Git-теги `<id>/vX.Y.Z` этого репозитория. Дальше их новые версии показывает сам BB (Settings → Updates, `bb plugin outdated`) и ставит `bb plugin update`. Перевод по одному: проверка сборки по тегу, сохранение и возврат настроек, проверка «запущен»; перерыв 4–23 секунды на плагин. Секретная настройка — остановка с вопросом владельцу. Плагины не из папки выпуска не трогаются.
- **Push Button 0.1.1**: Plugin SDK — рабочая зависимость, поэтому плагин собирается при установке из Git.
- **Subthread Autocollapse 0.1.1**: выпуск пробы Git-обновлений.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `plugins-git-source` — 12 плагинов bb-config получают обновления штатно от BB (Git-источник)

### Обновления плагинов — штатно через BB

Шаг `plugins-git-source` выполняется на сервере BB. Он переводит 12 плагинов
bb-config без секретов и расписаний (Subthread Autocollapse, Web BB Button,
Handoff Button, Project Machine Setup, Shared Guides, Git Thread Provenance,
Codex Goal Queue, Fresh Thread Hint, Project Open, Code Open, Thread Account
Usage, Push Button) с папки выпуска bb-config на Git-теги `<id>/vX.Y.Z`
публичного репозитория. После шага их новые версии показывает сам BB
(Settings → Updates, `bb plugin outdated`) и ставит `bb plugin update`;
Config Updates для них больше не нужен. Требуется BB 0.50 или новее.

Для каждого плагина по очереди: проверяется, что версия по тегу собирается
только с рабочими зависимостями (как при установке из Git); настройки
сохраняются в приватном журнале `.local/updates/plugin-git-source/`; BB 0.50
не меняет источник поверх установки, поэтому плагин удаляется и ставится из
Git (перерыв 4–13 секунд); настройки возвращаются и сверяются; проверяется
состояние `running`. Если у плагина появилась секретная настройка, которую
нельзя сохранить и вернуть, шаг останавливается и просит спросить владельца
установки. Плагины, которых нет или которые стоят не из папки выпуска
bb-config, не трогаются. Сбой — откат плагина на прежнюю папку выпуска с
прежними настройками и остановка.

Проверка: `python3 scripts/plugin_git_source.py --check <id> …`.
Откат одного плагина: `python3 scripts/plugin_git_source.py --rollback
--allow-remove <id>` (нужна сохранённая папка прежнего выпуска).

## Проверка релиза

Из чистого клона коммита выпуска: `python3 scripts/updates.py validate v1.13.0`, `python3 -m unittest discover -s scripts -p 'test_*.py'` (в том числе 11 тестов `test_plugin_git_source.py`), `python3 scripts/privacy_check.py --history`. Шаг пройден на установке автора: 12 плагинов на Git-источнике, все `running`, настройки совпали. Старые установки: прогон v1.0.0 → v1.12.0 на изолированном BB прошёл все 28 выпусков одним запуском.
