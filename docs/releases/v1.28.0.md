# v1.28.0 — Каскад подписок 0.4.0: модель важнее машины

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Модель важнее машины.** Каскад перебирает сначала модели по приоритету, внутри модели — машины.
  Ход не уходит на машину, где есть только модель хуже, пока текущая модель доступна на другой;
  возврат «на машину выше» — только к той же или лучшей модели.
- **402 от шлюза.** «Лимит тарифа исчерпан» — модель на этой ступени исчерпана, перепроверка через
  час. «Только в тарифе …» / «requires usage credits» — модель отмечается «недоступна на этой
  ступени» в таблице моделей и схеме «i», перепроверка раз в сутки; такая модель не пробуется.
- **Профили названы по модели:** «Лучшая модель · любая машина», «Лучшая модель · без Codex»,
  «Лучшая модель · подтреды на Codex», «Opus, потом лучшая»; подзаголовок — цепочка моделей.
  ID профилей прежние; имена, которые владелец менял сам, не трогаются.
- **Квота Codex видна там, где BB получает 403** (машины в RU): каскад спрашивает её у самого
  Codex на машине (`account/rateLimits/read`).

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `subscriptions-cascade-0-4-0` — Каскад подписок 0.4.0 — модель важнее машины, 402 «лимит» и «тариф» раздельно, квота Codex через сам Codex

«Авто» теперь называется «Лучшая модель · любая машина» и сначала выбирает модель, а потом машину: Opus на всех машинах по порядку, потом следующая модель. Ход больше не уходит с рабочего Opus на машину, где доступна только модель хуже.
- Ответ 402 «лимит тарифа исчерпан» считается исчерпанием с перепроверкой через час. Ответ «только в тарифе …» помечает модель «недоступна на этой ступени» и перепроверяется раз в сутки.
- Профили переименованы по модели («Opus, потом лучшая», «Лучшая модель · подтреды на Codex»), ID прежние. Подзаголовок профиля — цепочка моделей.
- Если BB не может прочитать квоту Codex (HTTP 403 на машинах с российским IP), каскад спрашивает её у самого Codex на машине.
Откат: тег agentcli-subscriptions-cascade/v0.3.9.
