Профиль каскада стал правилом на всё дерево тредов: у него есть часть для самого треда (self) и правило для всех потомков (descendants, в карточке профиля — «Потомки»). Потомок без явного профиля получает правило ближайшего предка, а явный выбор действует только на этот подтред. Если правило исчерпано, потомок по умолчанию ждёт сброса (`wait`); в режиме `fallback` он уходит на «Авто», не привязываясь к машине родителя (S11). Профиль «Авто · подтреды на Codex» пробует ступень Codex и при неизвестной квоте. Лимит Codex из хода теперь доходит до каскада.

Квота стала видна до хода. Ответ источника, пришедший позже бюджета хода, сохраняется. Показание не старше 15 минут с запасом считается известным, поэтому шлюз vclaude больше не показывает «неизвестно», и «Авто» возвращается на Claude. Новые команды: `bb subscriptions-cascade limits` (что видит каскад) и `check` (готовность ступени с подсказками; новая неготовая ступень пропускается с причиной). Тест-контракт сверяет квоту каскада и Thread Account Usage на общих образцах ответов. Подтреды запускаются только через каскад: `resolve` отдаёт модель, effort и готовые аргументы запуска, а «передай Codex» означает «Codex на любой машине». Если подтред запущен штатным провайдером, у родителя появляется строка «запущен мимо каскада». Настройки 0.3.4 читаются без изменений.
