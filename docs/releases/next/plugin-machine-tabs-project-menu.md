Machine Tabs 0.2.5 добавляет меню проектов в поле «Поиск тредов». Кнопка-папка
появляется при наведении на поле, рядом с воронкой. Наведение на неё показывает
компактный список проектов: поиск, быстрые фильтры (работают, ждут ответа,
ошибки, новое) и проекты по последней активности со счётчиками статусов тредов.
Щелчок по проекту прокручивает боковую панель к нему и подсвечивает группу.
Стрелка у проекта показывает его треды со статусами; щелчок открывает тред и
подсвечивает его в списке.

Проверка: `bb plugin list | grep machine-tabs` показывает 0.2.5; при наведении на
поле поиска рядом с воронкой видна кнопка-папка.
