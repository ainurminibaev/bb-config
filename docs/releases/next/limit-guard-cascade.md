Для треда «Каскада подписок» (providerId subscriptions-cascade) Limit Guard читает паспорт треда (RPC каскада threadStatus) и считает лимиты текущей ступени: её машины и провайдера. «Финиш» для такого треда смягчается до экономного режима: каскад сам переходит на следующую подписку между ходами. Ступень через шлюз квоты подписки не имеет — режим не выставляется. Тред каскада получает инструмент limit_status. Каскад не установлен или не ответил — поведение прежнее; треды Claude Code и Codex не меняются.
