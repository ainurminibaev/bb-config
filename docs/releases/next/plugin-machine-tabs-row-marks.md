Machine Tabs 0.2.4 показывает в строке треда значки, которые добавляют другие
плагины через `experimental_threadRowMetadata`: например, серую стрелку вниз
неприоритетного треда из Limit Guard, на паузе — стрелку с паузой. Значки стоят
справа от названия, рядом со статусом треда. Если ни один плагин значка не
даёт, строка не меняется.

Проверка: в боковом списке у неприоритетного треда видна стрелка вниз;
`bb plugin list | grep machine-tabs` показывает 0.2.4.
