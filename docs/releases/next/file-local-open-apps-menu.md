На сервере BB обновляет Open on Desktop до 0.3.0. Вместо трёх значков у ссылок
на файлы — один значок и правый клик по ссылке с общим меню: открыть на
компьютере, «Открыть с помощью» (приложения Mac для этого типа с иконками,
отсортированные по смыслу), «Поделиться» (скопировать файл в буфер обмена Mac,
путь, имя), сохранить в Загрузки и переход в штатное меню BB. HTML в браузере
открывается с локального сервера на Mac (127.0.0.1), поэтому работают скрипты,
модули и fetch(); переносятся и ресурсы, которые загружают скрипты, а битые
ссылки больше не ломают открытие. На Windows открывается приложение по
умолчанию. Повтор сверяет версию. Откат — file-local-open 0.2.0 из релиза v1.11.0.
