### Config Updates — штатно через BB

Config Updates 0.3.2 запоминает рабочую копию установки bb-config, пока стоит
из её папки, и находит её по памяти после перехода на Git-источник (или по
настройке «Рабочая копия bb-config»). Шаг переводит сам Config Updates на
Git-теги `config-updates/vX.Y.Z` тем же способом, что и остальные плагины.
Шаг идёт последним: до него Config Updates 0.3.2 ставится из папки выпуска
шагом `bundle` и успевает запомнить рабочую копию.
