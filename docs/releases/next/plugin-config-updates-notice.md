Обновляет Config Updates на сервере BB. Действие «Обновить с ИИ» показывается
в уведомлении о доступном релизе. Ручная проверка и описание релиза доступны
в настройках плагина.

После шага откройте меню «…» нижнего ряда и раздел «Обновления доработок» в
настройках. В меню больше нет пункта установщика доработок, а в настройках
доступна кнопка «Проверить сейчас». При новом релизе уведомление открывает
штатный экран нового треда BB с закреплённым заданием.
