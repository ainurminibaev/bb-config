Устанавливает на сервере BB новый плагин Thread Description 0.1.0. Штатный шаг
`local-plugin` собирает и ставит плагин из `plugins/thread-description` и
проверяет источник и версию.

У названия каждого треда появляется иконка с описанием, у поля ввода — кнопка
со сводкой. Описания создаются сами по первой задаче и обновляются не чаще раза
в час, когда открывают карточку. Генерация — обычный запрос к провайдеру на машине треда
(по умолчанию Claude Haiku, при отсутствии — другая доступная модель) и
расходует его лимит; выключается настройкой `enabled`.

Проверка: `bb thread-description models --thread <id>` показывает, чем будет
создано описание, `bb thread-description refresh --thread <id>` создаёт его.
