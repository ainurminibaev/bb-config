Кнопка «Обновить» открывает окно с новыми компонентами релиза: название,
ссылка на код, описание и галочка (по умолчанию включена). Снятая галочка
запоминается (`bundle.py choose --skip`), компонент не ставится и больше не
предлагается. Затем плагин сам запускает `updates.py apply` отдельным процессом
(он переживает перезапуск самого Config Updates) и показывает итог: что
установлено и обновлено, что нужно сделать самому (`attention`). Агент
(«Разобраться с ИИ») предлагается только при ошибке или остатке шагов.
Внешние плагины новее проверенной версии показываются предупреждением.
Нужен путь к bb CLI: по умолчанию `BB_CLI` сервера, иначе — в настройках.
