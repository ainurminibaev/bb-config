На сервере BB обновляет Limit Guard до 0.9.1. Новая настройка «Пороги по
аккаунтам» (`accountRules`), по умолчанию `$200: 80/85`: на подписках за $200
(Claude Max 20x, ChatGPT Pro) экономный режим и проверка темпа включаются не
раньше 80% 5-часового и 85% недельного окна, неприоритетные треды ниже этого не
ждут. Остальные аккаунты — как раньше. Тариф Claude читается из `~/.claude.json`
машины. Своё значение пользователя сохраняется. Повтор сверяет версию. Откат —
limit-guard 0.8.2 или пустое значение `accountRules`.

Заодно: сообщение `[limit-guard]` уходит только в идущий ход и больше не
начинает новый у треда, остановленного лимитом; продолжение при нескольких
исчерпанных окнах ждёт самого позднего сброса; при недоступном сервере BB
неприоритетный тред судит по цифрам не старше часа, а не пропускается.
