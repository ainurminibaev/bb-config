Удаляет плагин Subthread Error Mark. Machine Tabs (с 0.2.16) сам ставит красный ⊗
на тред с ошибкой, который BB не отмечает, в том числе на подтред, — в строке было
два одинаковых значка. После обновления остаётся один.

Проверка: `python3 scripts/plugin_retire.py check subthread-error-mark`; у подтреда с
ошибкой в боковой панели один ⊗.
