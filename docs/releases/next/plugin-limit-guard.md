Новый плагин Limit Guard. Работа не теряется, когда лимит подписки кончается
посреди хода.

- **Снимки незаконченной работы делает плагин.** Это коммит состояния папки
  под `refs/wip/bb/<окружение>`; файлы, ветка и индекс не меняются.
  - Для папок без git — теневой репозиторий на той же машине.
  - Когда: прерванный ход, режим финиша, затихший тред с правками, архивация
    worktree.
  - На сервер — только в приватный репозиторий и без похожих на секреты
    файлов.
- **Сообщение в идущий ход** Claude Code и Codex, когда режим ухудшился.
  Пороги: 5 часов — 75/90% или по темпу; неделя и окно модели — 90/97%.
- **Правила агенту:** ради лимита не коммитить; коммиты — только законченные
  шаги и свои файлы.
- **Застрявший тред:** уведомление, если ждать долго или автоповтора нет;
  предложение другой модели или сервиса (`bb limit stuck`). После
  `bb handoff` автоповтор исходного треда снимается.
- **Выключатели:** файл `.bb/hands-off` в папке,
  `bb plugin config limit-guard set snapshots local|off`,
  `bb plugin disable limit-guard`.

Проверка на сервере BB:

```sh
bb plugin list | grep limit-guard
bb limit status --thread <id треда Claude или Codex>
bb limit snapshot --thread <id>
bb limit snapshots
bb limit stuck
```

Правила попадают в сессию агента при её следующем запуске; уже работающие
треды получат их после перезапуска (`bb thread stop`, история сохраняется).
