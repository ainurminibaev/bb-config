Новый плагин Limit Guard. Агенты Claude Code и Codex получают инструмент
`limit_status` и короткие правила. Режим зависит от того, насколько заполнено
самое полное окно лимита подписки (5 часов, неделя, окно модели):

- обычный — до 70%;
- экономный — 70–89%: маленькие шаги, после каждого коммит своих файлов и push в
  текущую ветку;
- финиш — от 90%: новое не начинать, сохранить и написать «что сделано / что
  дальше / как проверить».

Force-push, чужие файлы и секреты правила запрещают. Плагин сам ничего не
коммитит и не останавливает ход. Пороги: `bb plugin config limit-guard set
economyPercent 70` и `finishPercent 90`.

Если ход всё же упал из-за лимита, а ждать сброса дольше часа или автоповтора
нет, приходит push-уведомление с предложением передать тред другому сервису с
запасом. `bb limit stuck` показывает такие треды и готовые команды. Сам плагин
тред не переносит.

Проверка на сервере BB:

```sh
bb plugin list | grep limit-guard
bb limit status --thread <id треда Claude или Codex>
bb limit stuck
```

Правила попадают в сессию агента при её следующем запуске; уже работающие
треды получат их после перезапуска (`bb thread stop`, история сохраняется).
