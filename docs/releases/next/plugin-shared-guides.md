Устанавливает на сервере BB плагин Shared Guides 0.1.0 — только навыки, без
интерфейса и инструментов: `bb-config-tracking`, `thread-transfer`,
`project-logos`, `agent-compat`. Общие инструкции BB (Custom instructions)
держат короткие триггеры «когда и что», а порядок действий загружается из этих
навыков по требованию.

Проверка: `bb skill list` показывает четыре навыка с источником plugin.
