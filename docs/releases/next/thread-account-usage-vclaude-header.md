Тред Claude Code на машине, где Claude Code настроен на шлюз VClaude
(`ANTHROPIC_BASE_URL` на `vclaude.ru`), раньше показывал в шапке
«не подтверждён» и «Лимиты не подтверждены»: BB не видит у такого Claude
входа в подписку. Теперь шапка такого треда показывает «VClaude» и остаток
пакета вместо колец, например «380,73 млн из 405 млн · до 27 дек», с цветом
по остатку (10 % и меньше — предупреждение). Клик открывает «Аккаунты и
объёмы» сразу на вкладке VClaude. Если кабинет VClaude недоступен —
«VClaude · остаток неизвестен». Остальные треды не меняются.
Машину плагин определяет по хосту `ANTHROPIC_BASE_URL` через метод машины из
0.2.3 (токены не передаются); машина со сборкой старше 0.2.3 шапку не меняет.
