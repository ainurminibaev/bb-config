На сервере BB обновляет Project Catalog до 0.8.0. Отдельная копия треда
вливается в основную папку только после `project_land` этого треда или когда
тред в архиве; между ходами копия и недоделанные коммиты остаются. Копия не
удаляется, если в ней есть игнорируемые файлы, которых нет в основной папке
(например `.local/`); папки сборки и зависимостей не мешают. При сбое списка
тредов или git ничего не трогается; ветка удаляется только когда она уже в
основной ветке. Повтор сверяет версию. Откат — project-catalog 0.7.0.
