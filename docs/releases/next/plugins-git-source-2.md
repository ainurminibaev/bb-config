### Обновления ещё 13 плагинов — штатно через BB

Шаг `plugins-git-source-2` продолжает `plugins-git-source` для плагинов с
расписаниями, своими данными или секретами: Project Logo, KodaForge Inspector,
Codex Delegation Watch, Context Mode Rollout, Menubar Status, File Local Open,
Plugin Keeper (voice-mode-keeper), Machine Tabs, PR и Issues, Browser Page,
Limit Guard, Project Catalog, Proxy Manager. После него их новые версии
показывает и ставит сам BB (Settings → Updates, `bb plugin update`).

Как и раньше, по одному: сборка по тегу до удаления, сохранение и возврат
настроек, проверка `running`. Что проверено на изолированном BB и на установке
автора: данные плагинов (хранилище и файлы) при переустановке сохраняются;
расписания регистрируются заново и работают (история запусков начинается
заново); секретные настройки BB при удалении стирает — поэтому шаг до
удаления копирует их во временный файл с правами 600 вне Git и журналов,
возвращает после установки, проверяет, что BB видит их заданными, и удаляет
файл. У Proxy Manager после шага прокси, привязки и маршруты те же, проверка
соединения проходит. Если секрет прочитать нельзя, шаг останавливается до
удаления и просит спросить владельца установки.

Config Updates остаётся в папке выпуска: ему нужен `scripts/updates.py`
рядом, а установка из Git этого не даёт.
