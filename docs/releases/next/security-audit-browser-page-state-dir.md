На сервере BB обновляет Browser Page до 0.1.1. Скрипт навыка bb-page хранит
адрес DevTools и файл подключения в каталоге `<tmp>/bb-page-<uid>` и отказывается
работать, если каталог принадлежит другому пользователю или открыт для других.
Состояние прежнего каталога `<tmp>/bb-page` не используется: открытые вкладки
нужно открыть заново командой `open`. Откат — browser-page 0.1.0 из релиза v1.11.0.
