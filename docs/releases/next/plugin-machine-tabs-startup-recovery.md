После старта BB режим Custom автоматически дожидается встроенного Thread List
и показывает треды без перезагрузки страницы. Состояние ожидания видно в панели.
Если сам BB сообщает об отключении или сбое встроенного плагина, Machine Tabs
указывает, где проверить его состояние.

Шаг проверяет версию и источник установленного Machine Tabs. Для обновления
он собирает и перезагружает плагин из закреплённых исходников. Проверка:
`node --test plugins/machine-tabs/tests/thread-list-bundle.test.mjs`.
