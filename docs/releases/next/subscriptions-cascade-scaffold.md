Появился экспериментальный плагин «Каскад подписок» (`agentcli-subscriptions-cascade`).
Свой провайдер BB: ход идёт на первой ступени «машина × CLI × аккаунт», у
которой есть лимит, CLI запускается на машине ступени, файлы проекта
синхронизирует Mutagen по общему пути. Экран настроек: машины (с «SSH к
опоре»), порядок ступеней, профили каскада со схемой «i», тестовый источник
квоты, таблица моделей, файлы и мастер «Настроить». Переход Claude ↔ Codex
внутри треда и карточка подтверждения в ходе — ещё в разработке.

Автоматически плагин не ставится и в набор (`config/bundle.json`) не входит.
Поставить вручную на сервере BB: `npm ci --prefix plugins/agentcli-subscriptions-cascade`,
`bb plugin build plugins/agentcli-subscriptions-cascade`,
`bb plugin install ./plugins/agentcli-subscriptions-cascade --yes`.
Проверка: Настройки → Плагины → «Каскад подписок» открывает экран каскада;
в выборе провайдера появляется «Каскад подписок» с профилями «Авто»,
«Авто · без Codex», «Opus → Авто», «Fable → Авто», «Только Opus 5.5», «Только Fable 5.2». Запишите результат через `record` с тем, что увидели, или отказ.
