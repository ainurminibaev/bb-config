порядок агентов и оркестраторов в раскрытой группе. В «Last 5» наведите курсор
на раскрытого родителя — на месте счётчика появляется стрелка. Повторная
проверка работает без переустановки. Для отката используйте тег machine-tabs/v0.2.18.
