# Размещение индикаторов лимитов в шапке и сайдбаре

Логотип провайдера располагается в центре кольца, а счётчик доступных сбросов занимает отдельное место справа. На узком десктопном экране дополнительная подпись графика скрывается. Значения лимитов доступны в карточке аккаунта.

На сервере BB проверьте источник и текущую версию через `bb plugin source thread-account-usage` и `bb plugin list`. Для локальной установки примените шаг обновления из checkout релиза. Ожидаемая версия — 0.1.1, статус — running. Повторите проверку после перезагрузки интерфейса.

Вернуть предыдущую версию плагина из сохранённого checkout, пересобрать и перезагрузить его.
