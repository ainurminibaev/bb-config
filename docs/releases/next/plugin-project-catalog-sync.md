Project Catalog 0.4.0 добавляет синхронизацию папки проекта перед работой.

- Агент в треде проекта получает инструмент `project_sync` и правило: вызвать
  его один раз до первых правок. Выполняется `git fetch`, а подтягивание —
  **только fast-forward чистой ветки**. Если есть правки, ветки разошлись или
  нет связи, ничего не меняется, а агент объясняет причину.
- В ответе: новые коммиты и состояние копий на других машинах по последней
  проверке каталога.
- Для папки без git проверяются вложенные репозитории (до двух уровней).
- `bb catalog pull [--check] [--thread <id>]` и `bb catalog history [проект]`.
  В карточке на вкладке «Проекты» появился блок «Синхронизация».

Проверка на сервере BB:

```sh
bb plugin list | grep project-catalog
bb catalog pull --check --thread <id треда проекта>
bb catalog history <проект>
```
