Project Catalog 0.6.0 добавляет синхронизацию папки проекта перед работой и список worktree-копий.

- При первом сообщении треда проекта плагин сам делает `git fetch` и
  подтягивает свежее — **только fast-forward чистой папки**, где не работает
  другой тред и нет файла `.bb/hands-off`. Ждёт не дольше 20 секунд, итог
  кладёт в инструкции сессии. Иначе ничего не меняет и объясняет причину.
  Повторить вручную: инструмент `project_sync` или `bb catalog pull`.
- Каждые 30 минут — fetch проектов с активностью за неделю (меняются только
  сведения о сервере) и удаление записей BB о worktree без папки и без живых
  тредов.
- В ответе: новые коммиты и состояние копий на других машинах по последней
  проверке каталога.
- Для папки без git проверяются вложенные репозитории (до двух уровней).
- `bb catalog pull [--check] [--thread <id>]` и `bb catalog history [проект]`.
  В карточке на вкладке «Проекты» появился блок «Синхронизация».

- `bb catalog worktrees [проект]` и блок «Worktree» в карточке: копии, которые
  BB создал для тредов, с размером и состоянием. Забытые копии и записи без
  папки идут первыми. Плагин ничего не удаляет.

Проверка на сервере BB:

```sh
bb plugin list | grep project-catalog
bb catalog pull --check --thread <id треда проекта>
bb catalog history <проект>
bb catalog worktrees
```
