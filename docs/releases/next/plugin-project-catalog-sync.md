Project Catalog 0.7.0 синхронизирует папку проекта перед работой, показывает
worktree-копии и изолирует второй тред в занятой папке.

- **Первое сообщение треда** ненадолго встаёт в очередь («Синхронизирую папку
  проекта»). Плагин делает `git fetch` и подтягивает свежее — **только
  fast-forward чистой папки**, где никто больше не работает и нет файла
  `.bb/hands-off`. Затем сообщение уходит, итог — в инструкциях агента.
  Настройка `autoPull`: `auto` / `check` / `off`. Вручную: `project_sync`
  или `bb catalog pull [--check]`.
- **Занятая папка.** Если там уже работает другой тред, агент до правок
  вызывает `project_isolate` и работает в своей копии (git worktree на своей
  ветке). Закоммиченное плагин вольёт обратно сам, когда основная папка
  освободится; при конфликте ничего не меняет и сообщает.
- `bb catalog history` и блок «Синхронизация» в карточке; `bb catalog
  worktrees` и блок «Worktree»: размер и состояние копий, забытые — первыми.
- Каждые 30 минут — fetch активных за неделю проектов (только сведения о
  сервере). Удаление записей о worktree без папки — только если включить
  `cleanupMissingWorktrees`.

Проверка на сервере BB:

```sh
bb plugin list | grep project-catalog
bb plugin config project-catalog
bb catalog pull --check --thread <id треда проекта>
bb catalog history <проект>
bb catalog worktrees
```
