# Выбор проекта при создании треда

В режиме Custom верхняя кнопка New thread открывает черновик без проекта. Кнопка «+» в ручной папке выбирает проект папки и сохраняет размещение треда. Для новой папки выберите проект при создании первого чата. Для существующей папки без явной привязки берётся самый ранний самостоятельный чат с проектом, включая архив.

На сервере BB проверьте источник и текущую версию через `bb plugin source machine-tabs` и `bb plugin list`. Для локальной установки примените шаг обновления из checkout релиза. Ожидаемая версия — 0.2.2, статус — running. Повторите проверку после перезагрузки интерфейса.

Вернуть предыдущую версию плагина из сохранённого checkout, пересобрать и перезагрузить его.
