На сервере BB обновляет Machine Tabs до 0.2.7. Под длинными списками в боковой
панели больше нет пустой полосы под «Показать ещё». Кнопка «↓ ещё N · 5/22»
всплывает маленькой плашкой в правом нижнем углу списка, только пока на него
наведён указатель; у вложенных списков — только у ближайшего. На сенсорных
экранах кнопка остаётся обычной строкой под списком. Повтор сверяет версию.
Откат — machine-tabs 0.2.6 из релиза v1.10.0.
