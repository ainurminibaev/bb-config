### `plugin-knowledge-base` — личная база знаний из любого треда

Выполняется на сервере BB, зависимостей нет. Новый необязательный компонент:
спросите пользователя, ведёт ли он базу знаний в git-репозитории на сервере BB
(структура `topics/<topic>/items/NNN-slug.md` и `scripts/kb-rebuild.py`).

Плагин даёт всем тредам (Claude Code, Codex; любая машина) инструменты
`kb_search`, `kb_read`, `kb_topics`, `kb_add`, навык `knowledge-base` и команду
`bb kb search|read|topics|add|remove`. Код выполняется на сервере BB, поэтому
агентам на других машинах база доступна без копирования. `kb_add` проверяет
дубли по источнику и slug, ставит следующий id в теме, пересобирает индексы и
делает локальный коммит только своих файлов (без push).

Пока не задан путь, инструменты не подключаются. Установка: в
`plugins/knowledge-base` выполнить `npm ci --include=dev`, `bb plugin install .`,
затем `bb plugin config knowledge-base set root <абсолютный путь к базе>`.

Шаг уже применён, если `bb plugin list` показывает `knowledge-base` версии
0.2.0 в состоянии running и `bb kb topics` возвращает темы базы. Проверка
поведения: в новом треде другого проекта попросить найти материал в базе —
агент вызывает `kb_search`/`kb_read`.
