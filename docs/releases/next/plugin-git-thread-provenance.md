### Git Thread Provenance 0.1.0

Опциональный серверный компонент. Новым сессиям Codex и Claude Code во всех
проектах этого BB передаётся общая инструкция о трейлере собственного нового
коммита, строке в новом PR и записи фактического результата push в треде.
Правила публикации каждого репозитория применяются перед добавлением метки.

Шаг `local-plugin` собирает и устанавливает `plugins/git-thread-provenance`
на сервере. Проверка установки — версия 0.1.0 и статус `running` в
`bb plugin list --json`. Для проверки поведения откройте новый тред Codex и
попросите создать коммит в одноразовом локальном репозитории без remote,
подготовить текст PR без отправки и показать трейлер коммита. В обоих случаях
ожидается одна строка с ID этого треда. Поиск — `bb thread show <id>`.

Для отката выполните `bb plugin disable git-thread-provenance` и дождитесь
следующей сессии провайдера. Уже опубликованные объекты сохраняются.
