Задание агенту для «Обновить с ИИ» сводится к одной команде
`python3 scripts/updates.py apply <тег> --commit <sha> --repository <owner/repo>`:
она скачивает закреплённый релиз, сводит установку к полному набору, проверяет
шаги пропущенных релизов и пишет журнал. Агент отдельно и явно перечисляет
пункты `attention` (личные входы, настройки, действия на других машинах).
Плагин обычно уже обновлён шагом `bundle`; этот шаг проверяет версию 0.2.0.
