Аккаунты VClaude различаются по машинам.

**Аккаунт машины.** Машина сообщает серверу BB короткий ID аккаунта VClaude —
первые 8 символов sha256 ключа шлюза (`ANTHROPIC_AUTH_TOKEN` или
`ANTHROPIC_API_KEY` из `env` в `~/.claude/settings.json`, иначе из окружения).
Сам ключ машину не покидает и нигде не хранится. Машины с одним ключом — одна
строка, под ней список машин.

**Подпись и логотип.** В «Все аккаунты», на странице «Аккаунты и объёмы» и в
шапке треда вместо общего «VClaude» стоит почта кабинета или ручная метка, со
своим значком VClaude (простая «V», не логотип сервиса). Почта берётся из
ответа кабинета, если он её сообщает, иначе из входа кабинета на сервере BB
(`login.json`, только поле email). Ручная метка — настройка плагина
`vclaudeLabels`: JSON `{"<ID>": "<метка>"}`; ID виден в подсказке строки
(«VClaude · <ID>»).

**Несколько аккаунтов.** Кабинет на сервере BB один. Его остаток относится к
единственному ключу, а при нескольких ключах — к тому, чья метка равна почте
кабинета. Остальные аккаунты показаны своими строками с машинами и пометкой
«Кабинет этого аккаунта не подключён»; без сопоставления остаток кабинета —
отдельной строкой без машин. Машины со сборкой хоста старше 0.3.2 (без ID)
остаются под строкой кабинета, как раньше.

**Шапка треда VClaude** — подпись аккаунта той машины, где идёт ход (и для
ступени каскада через VClaude).

Один аккаунт выглядит как раньше, плюс подпись и значок. Откат: тег
thread-account-usage/v0.3.1.
