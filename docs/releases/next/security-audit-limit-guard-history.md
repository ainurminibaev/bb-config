На сервере BB обновляет Limit Guard до 0.8.2. При режиме snapshots=push-private
перед отправкой снимка в приватный репозиторий проверяются все версии файлов во
всех коммитах, которых ещё нет на origin (раньше — только итоговая разница). Если
секрет остался в предыдущем локальном снимке, отправляется снимок без этой
цепочки; если секрет есть в неотправленных коммитах ветки, снимок остаётся только
на машине. Повтор сверяет версию. Откат — limit-guard 0.8.1 из релиза v1.11.0.
