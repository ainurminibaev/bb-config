Project Logo 0.2.2. Навык `project-logo` раньше не доходил до агентов: плагин
передавал BB пустой список навыков. Теперь навык доступен во всех тредах
обычных проектов. После автоматической проверки значка инструменты скрыты, а
навык остаётся и описывает явную просьбу «поставь/замени логотип проекта»
через `bb project-logo` и ручную замену `.bb/icon.*`.

Проверка: в новом треде обычного проекта среди навыков есть `project-logo`.
