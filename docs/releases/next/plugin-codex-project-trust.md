Устанавливает плагин Codex Project Trust на сервер BB. Нужен BB 0.50.1
или новее. Для подтверждения доверия на машине треда нужен Codex CLI
0.170.0 или новее.

Шаг проверяет установленный источник и версию. Если плагина ещё нет, он
ставится из стабильного Git-тега отдельного публичного репозитория. Проверка
подтверждает, что управляемая сборка v1 запущена, или учитывает явное отключение
пользователем. Установка из другого источника требует проверки владельцем.

Повтор проверяет текущую установку. Отключение плагина убирает карточку.
Пользователь подтверждает каждый путь отдельно в треде. Шаг обновления не
меняет доверие к проектам и настройки Codex.
