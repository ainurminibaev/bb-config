Две доработки шапки треда в одной версии (0.3.0 совместимости с каскадом и
0.2.4 шапки VClaude сведены в 0.3.1).

**Тред «Каскада подписок».** Кольцо в шапке показывает квоту текущей ступени:
провайдера, машину и аккаунт из паспорта каскада; в подписи — «ступень
каскада». Каскад не установлен или не ответил за 3 с — как раньше.

**Тред Claude Code через VClaude.** Тред на машине, где Claude Code настроен на
шлюз VClaude (`ANTHROPIC_BASE_URL` на `vclaude.ru`), раньше показывал
«не подтверждён» и «Лимиты не подтверждены». Теперь шапка показывает «VClaude»
и остаток пакета вместо колец, например «380,73 млн из 405 млн · до 27 дек», с
цветом по остатку (10 % и меньше — предупреждение). Клик открывает «Аккаунты и
объёмы» на вкладке VClaude. Кабинет недоступен — «VClaude · остаток неизвестен».
Машину плагин определяет по хосту `ANTHROPIC_BASE_URL` через метод машины из
0.2.3 (токены не передаются); машина со сборкой старше 0.2.3 шапку не меняет.

**Тред каскада на VClaude.** Главный признак — ступень каскада `kind: gateway`
VClaude: шапка та же, остаток пакета. Запасной путь — ступень-подписка Claude
Code на машине, чей Claude Code направлен на VClaude.

Остальные треды не меняются. Откат: тег thread-account-usage/v0.2.3.
