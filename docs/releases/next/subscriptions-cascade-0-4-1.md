Профили по умолчанию стали такими: «Авто Opus · с Codex / без Codex / подтреды только Codex», то же для Fable, «Только Opus 5.5», «Только Fable 5.2», «Только Codex». В существующих настройках обновляются только профили со стандартными именами; новые добавляются в конец один раз, порядок и свои имена владельца не меняются. Прежний «Opus → Авто» скрыт из списка, но старые треды на нём работают.
Если ход идёт не на машине треда, в конец сообщения хода добавляется короткая строка: где выполняется ход и что задачи про саму машину (деплой, nginx и https, пакеты, диск, сервисы, порты) нужно выполнять на машине, о которой речь, через `bb terminal run --machine`. В окружении CLI есть машина треда, машина ступени и список машин.
Откат: тег agentcli-subscriptions-cascade/v0.4.0.
