В «Все аккаунты» → «Пакеты» под подписью VClaude видна машина, где Claude Code
настроен расходовать этот пакет, — так же, как Tru под «Прямой Gemini». Машину
определяет сам плагин: на каждой машине он читает из `settings.json` Claude Code
только хост `ANTHROPIC_BASE_URL` (токены не передаются) и показывает те машины,
где это `vclaude.ru`, под их текущим именем в BB. Квоту по-прежнему читает
сервер BB; квота, срок, процент и переход в подробности не изменились.
Машина со старой сборкой плагина в строку не попадает до обновления.
Откат: тег thread-account-usage/v0.2.2.
