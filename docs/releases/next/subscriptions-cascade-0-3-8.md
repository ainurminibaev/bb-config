Ступень шлюза VClaude больше не показывает «квота неизвестна», когда кабинет отдаёт пакет. Показание пакета считается свежим 20 минут при любом проценте (`packageFreshMinutes`), потому что кабинет обновляется раз в 10–15 минут. После обнаружения машин квота ступеней без показания читается сразу, а не при первом ходе. Живой ответ кабинета добавлен образцом в тест-контракт.
