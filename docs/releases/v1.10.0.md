# v1.10.0 — Machine Tabs 0.2.6: меню проектов ближе и быстрее

## Что изменилось

- **Machine Tabs 0.2.6.** Меню проектов в поле «Поиск тредов» открывается
  вплотную под самим полем, а не под всей строкой поиска с фильтрами, поэтому
  оказывается рядом с указателем.
- Задержка открытия при наведении на поле — ~0,3 с вместо 0,65 с.

Общий порядок — [docs/updates.md](../updates.md).

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `plugin-machine-tabs-menu-closer` — Machine Tabs 0.2.6: меню проектов ближе к указателю и быстрее

Machine Tabs 0.2.6: меню проектов открывается сразу под полем «Поиск тредов»,
а не под всей строкой с фильтрами, поэтому оказывается ближе к указателю.
Наведение на само поле открывает меню через ~0,3 с вместо 0,65 с.

Проверка: `bb plugin list | grep machine-tabs` показывает 0.2.6; при наведении
на поле поиска меню появляется вплотную под полем.

## Проверка релиза

- `python3 scripts/updates.py validate v1.10.0` и `python3 -m unittest discover -s scripts -p 'test_*.py'` из чистого клона коммита релиза.
- Тесты Machine Tabs (`node --test plugins/machine-tabs/tests/*.test.mjs`) и `tsc --noEmit`.
