# v1.23.0 — Каскад подписок 0.3.3, Mac Computer Use 0.5.0, Browser Relay 0.2.0

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Каскад подписок 0.3.3.** «Открыть папку», открытие файлов и путь к коду у треда на
  каскаде ведут в папку проекта (или рабочую копию треда), а не в общий корень реплик
  `/opt/bbfs`. Если машину убрали из каскада, строка перехода называет её по имени и пишет
  «убран из каскада», а не ID хоста и «не на связи».
- **Mac Computer Use 0.5.0.** Кнопка «Стоп» на плашке Mac работает и прерывает действия
  в полёте; тред остаётся остановленным до явного «Разрешить снова».
- **Browser Relay 0.2.0.** Одно «Allow» с долгим ожиданием, честный статус подключения
  к Chrome, остановка по треду. После обновления Chrome один раз попросит «Allow».

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `browser-relay-connect-stop` — Browser Relay 0.2.0 — одно «Allow» с долгим ожиданием, честный статус, остановка по треду

`bb browser-relay status` показывает, подключена ли служба к Chrome, а не только
отвечает ли она. `bb browser-relay connect` делает одну попытку подключения и ждёт
одно «Allow» до 10 минут без повторов. `stop --thread`/`--all` и `resume` останавливают
агента в браузере; список остановок общий с Mac Computer Use.

После обновления плагина один раз выполните на Mac с Chrome
`bb browser-relay service install --machine <Mac>`: служба перезапустится с долгим
ожиданием «Allow», затем `bb browser-relay connect` и одно нажатие «Allow».
Откат: тег v0.1.0.

### `mac-computer-use-stop` — Mac Computer Use 0.5.0 — «Стоп» работает и прерывает действия в полёте

Кнопка «Стоп» на плашке Mac теперь получает нажатия. Остановка прерывает действие
в полёте (пакет шагов, AppleScript), останавливает ход треда в BB и держит доступ
треда к Mac закрытым до явного «Разрешить снова» — срока в 12 часов больше нет.
Остановка треда в BB во время действия на Mac делает то же. Новые команды:
`bb mac-computer-use stop --thread thr_…`, `resume`, `stopped`. Пока тред остановлен,
сообщения агентов и автоматизаций ему ждут; ваши сообщения проходят.
Откат: тег v0.4.3.

### `subscriptions-cascade-0-3-3` — Каскад подписок 0.3.3 — «Открыть папку» и файлы треда ведут в папку проекта; понятная строка, когда машину убрали из каскада

Паспорт треда каскада (`threadStatus.path`) теперь указывает папку актуальной копии файлов треда: на опоре — checkout проекта или worktree треда, на исполнителе с неотданными правками — его реплика `<общий путь>/<папка проекта>`. Раньше там был общий корень реплик (`/opt/bbfs`), и «Открыть папку» (Project Open), открытие файлов (File Local Open) и путь для кода вели в него, а не в проект. Плагины-читатели паспорта менять не нужно.
Откат: тег agentcli-subscriptions-cascade/v0.3.2.
Строка перехода после того, как машину убрали из каскада, теперь «Mac убран из каскада → …» с именем машины; раньше там стоял ID хоста и неверная причина «не на связи».
