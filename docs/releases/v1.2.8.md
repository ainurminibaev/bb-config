# v1.2.8 — Звук Voice Mode 0.2.6 и мост Codex Live

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Voice Mode из стабильного канала форка обновляется до
  [0.2.6](https://github.com/ainurminibaev/bb-plugin-voice-mode/releases/tag/v0.2.6)
  штатно в BB: устранены прерывания и рост задержки звука на маршруте

- Новый скрипт `scripts/voice_mode_bridge.py --check|--apply` держит копию моста

  обновления Voice Mode.

## Шаги

### `voice-mode-bridge-0-2-6` — Voice Mode 0.2.6: мост Codex Live в паре с плагином

Voice Mode 0.2.6 из стабильного канала форка перестраивает звук маршрута
Codex Live 1.1 (`codex-live-first`): адаптивный джиттер-буфер в браузере,
ограниченная очередь микрофона в мосте, без приглушения по громкости. Плагин
обновляется штатно в BB (`bb plugin update voice-mode`), а копию моста
`codex_voice.py` в `~/.local/share/bb-voice-mode/codex-live/` обновление
плагина не трогает. Шаг выполняется на сервере BB под пользователем службы.

1. Неприменим, если Voice Mode не установлен. Ждёт, пока установленная версия
   не станет 0.2.6 или новее (`requiresPlugins`): сначала обновите плагин в BB.
2. Применён, если моста нет (маршрут не используется) или его копия совпадает
   по SHA-256 с `codex_voice.py` установленного плагина.
3. `--apply` запускает штатный `codex_voice.py --install` из каталога
   установленного плагина (путь берётся из `bb plugin list --json`): venv,
   `aiortc==1.16.0` и копия моста. Нужны Python 3.12 с venv и Codex CLI,
   вошедший через ChatGPT (`codex login status`).
4. Меняется только копия моста и venv в каталоге Voice Mode; настройки и
   секреты плагина не затрагиваются.
5. Ожидаемо: `python3 scripts/voice_mode_bridge.py --check` печатает
   `"bridge": "current"` (или `route-unused`) и завершается с кодом 0. Активный
   звонок нужно начать заново.
6. Повтор безопасен.
7. Откат: установить v0.2.5 (см. `rollback`) и повторить `--apply`. Мост и
   браузер 0.2.5/0.2.6 совместимы между собой, новое поведение работает только
   при обеих сторонах 0.2.6.

- `python3 scripts/privacy_check.py --history`.
