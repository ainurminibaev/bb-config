# v1.4.0 — Единая установка и обновление полного набора

Общий порядок — [docs/updates.md](../updates.md). Состав — [docs/components.md](../components.md).

## Что изменилось

- Набор bb-config объявлен в `config/bundle.json`: 26 компонентов — свои плагины,
  собственные форки и репозитории (Voice Mode, Codex Project Trust) и плагины
  каталога, от которых они зависят (Handoff, Needs You, Tokenomics, KodaForge,
  ChatGPT Realtime Connection).
- Установка на чистой машине — одно действие: `python3 scripts/updates.py apply`
  из свежего checkout (последний стабильный релиз, весь набор, проект BB, журнал).
- Обновление — одно действие (`apply` с тегом и коммитом, его и запускает
  «Обновить с ИИ»): ставит недостающие компоненты и обновляет устаревшие,
  включая форки и каталоговые плагины; затем проверяет шаги пропущенных релизов.
- Исправлена регрессия v1.3.1 (и v1.2.8): отсутствующий Voice Mode больше не
  пропускается, а старый не требует отдельного обновления. Те же пропуски
  закрыты для KodaForge, своих плагинов, не входивших в ваши прежние шаги,
  Local Transcribe и зависимостей из каталога (список — в components.md).
- Сохраняются: настройки и секреты (только штатные `bb plugin install/update`,
  без удаления; диапазон версии меняется на месте), отключённые плагины,
  исключённые (`scripts/bundle.py exclude <id>`) и ранее отклонённые компоненты,
  плагины из другого источника и более новые сборки.
- Личные входы, личные настройки плагинов и действия на других машинах
  выводятся отдельным списком `attention`; журнал хранит фактическое состояние
  каждого компонента.
- Повтор `apply` доделывает остаток после сбоя и чинит расхождения.

**Перед обновлением**: если какой-то компонент набора вам не нужен, исключите
его — `python3 scripts/bundle.py exclude <id>` из checkout релиза
(`.local/updates/releases/<коммит>`); иначе обновление его установит.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `plugin-config-updates-one-step` — Config Updates 0.2.0: обновление одним действием

Задание агенту для «Обновить с ИИ» сводится к одной команде
`python3 scripts/updates.py apply <тег> --commit <sha> --repository <owner/repo>`:
она скачивает закреплённый релиз, сводит установку к полному набору, проверяет
шаги пропущенных релизов и пишет журнал. Агент отдельно и явно перечисляет
пункты `attention` (личные входы, настройки, действия на других машинах).
Плагин обычно уже обновлён шагом `bundle`; этот шаг проверяет версию 0.2.0.

## Проверка релиза

Изолированные экземпляры BB 0.50.1 (свои данные, порты и HOME), закреплённый
кандидат релиза из локального origin:

- Чистая установка: `apply` поставил все 26 компонентов (свои — из
  закреплённого коммита, форк Voice Mode 0.2.8, каталоговые), создал проект BB;
  журнал — v1.4.0, 51 шаг проверен. ChatGPT Realtime, Menubar Status и Web BB
  Button в состоянии `needs-configuration` попали в `attention`.
- Сбой и восстановление: первый прогон кандидата остановился на шаге `bundle`
  (шаги старых релизов — `blocked`, версия не повышена); повторный `apply`
  довёл установку до v1.4.0 без переустановки готового.
- Переход с v1.3.1 (воспроизведена регрессия: шаг Voice Mode `not-applicable`)
  с Machine Tabs, Push Button (отключён), Handoff Button, Config Updates 0.1.7 и
  отказом от Subthread Autocollapse: поставлено 20 компонентов, включая Voice
  Mode 0.2.8 и ChatGPT Realtime; 4 обновлены; Push Button остался отключённым;
  Subthread Autocollapse не установлен.
- Переход с v1.3.0 со старым Voice Mode 0.2.5 (воспроизведена регрессия:
  v1.3.1 падает на `requiresPlugins`): Voice Mode обновлён до 0.2.8 сменой
  сохранённого диапазона, личная настройка голоса сохранилась, шаг v1.3.1
  проверен, установлена v1.4.0.
- Повторное применение: без изменений; после удаления плагина и отключения
  другого повтор вернул удалённый и оставил отключённый отключённым.
- `python3 -m unittest discover -s scripts -p 'test_*.py'`, `npm test` в
  `plugins/config-updates`, `updates.py validate v1.4.0` из чистого клона,
  `privacy_check.py --history`.

Ограничения: плагин, закреплённый на точном теге, не переводится автоматически
(BB не меняет диапазон; удаление стёрло бы секреты) — ошибка с пояснением.
Штатно удалённый компонент без `exclude` ставится снова. Действия на других
машинах и личные входы выполняет пользователь (`attention`).
