# v1.16.0 — Config Updates 0.3.2 — тоже обновляется штатно через BB

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Config Updates 0.3.2 тоже обновляется штатно через BB.** Плагин запоминает рабочую копию установки bb-config при запуске из её папки и находит её после перехода на Git-источник (или по новой настройке «Рабочая копия bb-config»). Шаг `config-updates-git-source` идёт последним и переводит сам Config Updates на теги `config-updates/vX.Y.Z`. Переход работает и одной кнопкой из Config Updates 0.3.1: обновление доходит до конца само.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `config-updates-git-source` — Config Updates получает обновления штатно от BB (Git-источник)

### Config Updates — штатно через BB

Config Updates 0.3.2 запоминает рабочую копию установки bb-config, пока стоит
из её папки, и находит её по памяти после перехода на Git-источник (или по
настройке «Рабочая копия bb-config»). Шаг переводит сам Config Updates на
Git-теги `config-updates/vX.Y.Z` тем же способом, что и остальные плагины.
Шаг идёт последним: до него Config Updates 0.3.2 ставится из папки выпуска
шагом `bundle` и успевает запомнить рабочую копию.

## Проверка релиза

Из чистого клона коммита выпуска: `python3 scripts/updates.py validate v1.16.0`, `python3 -m unittest discover -s scripts -p 'test_*.py'`, тесты Config Updates (15), `python3 scripts/privacy_check.py --history`. На изолированном BB: чистая установка v1.15.0 с Config Updates 0.3.1 → 0.3.2 из папки выпуска → перевод на Git → проверка и применение следующих выпусков из Git-установки (RPC и кнопка в браузере); переход одной кнопкой с 0.3.1 завершился сам (`done`, код 0); без памяти — понятная ошибка, с настройкой — работает.
