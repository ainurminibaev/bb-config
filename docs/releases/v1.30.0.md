# v1.30.0 — Каскад подписок 0.4.1: профили «Авто Opus/Fable», «Только Codex», агент знает, на какой машине выполняется

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Профили по умолчанию:** «Авто Opus · с Codex», «Авто Opus · без Codex», «Авто Opus · подтреды только
  Codex», то же для Fable, «Только Opus 5.5», «Только Fable 5.2», «Только Codex» (Codex любой машины,
  без подтверждения). «Авто <модель>» — сначала эта модель на всех машинах, потом лучшая. В
  существующих настройках переименовываются только стандартные имена; новые профили добавляются один
  раз в конец; прежний «Opus → Авто» скрыт, старые треды на нём работают.
- **Агент знает, где выполняется.** Если ход идёт не на машине треда, в конец сообщения хода
  добавляется короткая стабильная строка: где выполняется ход, что задачи про саму машину (деплой,
  nginx/https, docker, systemd, пакеты, диск, сервисы, порты, firewall, логи) выполняются на
  машине, о которой речь («эта машина» — машина треда), и команда `bb terminal run --machine …`.
  Кэш промптов не страдает: системный промпт не меняется. В окружении CLI — `BB_CASCADE_HOME_HOST`,
  `BB_CASCADE_HOME_LABEL`, `BB_CASCADE_EXEC_HOST`, `BB_CASCADE_MACHINES`.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `subscriptions-cascade-0-4-1` — Каскад подписок 0.4.1 — профили «Авто Opus/Fable», «Только Codex», строка «где я выполняюсь»

Профили по умолчанию стали такими: «Авто Opus · с Codex / без Codex / подтреды только Codex», то же для Fable, «Только Opus 5.5», «Только Fable 5.2», «Только Codex». В существующих настройках обновляются только профили со стандартными именами; новые добавляются в конец один раз, порядок и свои имена владельца не меняются. Прежний «Opus → Авто» скрыт из списка, но старые треды на нём работают.
Если ход идёт не на машине треда, в конец сообщения хода добавляется короткая строка: где выполняется ход и что задачи про саму машину (деплой, nginx и https, пакеты, диск, сервисы, порты) нужно выполнять на машине, о которой речь, через `bb terminal run --machine`. В окружении CLI есть машина треда, машина ступени и список машин.
Откат: тег agentcli-subscriptions-cascade/v0.4.0.
