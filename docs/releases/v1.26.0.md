# v1.26.0 — Каскад подписок 0.3.8 и Thread Account Usage 0.3.4: остаток пакета VClaude виден каскаду

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Каскад видит остаток пакета VClaude.** Сразу после обнаружения машин каскад в фоне читает квоту
  всех включённых ступеней, в том числе шлюзов (раньше шлюз ждал первого хода). Показание пакета
  считается свежим 20 минут при любом остатке (`packageFreshMinutes`): кабинет обновляется раз в
  10–15 минут, и почти израсходованный пакет больше не становится «неизвестным» через минуту.
- **Тест-контракт:** обезличенный ответ кабинета VClaude — общий образец для каскада и
  Thread Account Usage 0.3.4; оба плагина должны видеть на нём одинаковый процент и остаток.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `subscriptions-cascade-0-3-8` — Каскад подписок 0.3.8 — квота шлюза vclaude известна между ходами и после переустановки

Ступень шлюза VClaude больше не показывает «квота неизвестна», когда кабинет отдаёт пакет. Показание пакета считается свежим 20 минут при любом проценте (`packageFreshMinutes`), потому что кабинет обновляется раз в 10–15 минут. После обнаружения машин квота ступеней без показания читается сразу, а не при первом ходе. Живой ответ кабинета добавлен образцом в тест-контракт.
Откат: тег agentcli-subscriptions-cascade/v0.3.7.

### `thread-account-usage-0-3-4` — Thread Account Usage 0.3.4 — образец живого ответа VClaude в сверке с каскадом

Поведение панели не меняется. В общий файл образцов `fixtures/limits-samples.json` добавлен живой ответ VClaude, и тест сверяет с каскадом его процент и остаток.
Откат: тег thread-account-usage/v0.3.3.
