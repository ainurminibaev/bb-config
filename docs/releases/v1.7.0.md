# v1.7.0 — Git Thread Provenance 0.1.0

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Добавлен опциональный серверный плагин Git Thread Provenance 0.1.0. Он
  передаёт новым сессиям Codex и Claude Code инструкцию о связи коммитов,
  pull request и результатов push с рабочим тредом BB. Метку можно
  публиковать только с учётом правил репозитория и указаний пользователя.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `plugin-git-thread-provenance` — Git Thread Provenance 0.1.0

Опциональный серверный компонент. Новым сессиям Codex и Claude Code во всех
проектах этого BB передаётся общая инструкция о трейлере собственного нового
коммита, строке в новом PR и записи фактического результата push в треде.
Правила публикации каждого репозитория применяются перед добавлением метки.

Шаг `local-plugin` собирает и устанавливает `plugins/git-thread-provenance`
на сервере. Проверка установки — версия 0.1.0 и статус `running` в
`bb plugin list --json`. Для проверки поведения откройте новый тред Codex и
попросите создать коммит в одноразовом локальном репозитории без remote,
подготовить текст PR без отправки и показать трейлер коммита. В обоих случаях
ожидается одна строка с ID этого треда. Поиск — `bb thread show <id>`.

Для отката выполните `bb plugin disable git-thread-provenance` и дождитесь
следующей сессии провайдера. Уже опубликованные объекты сохраняются.

## Проверка релиза

- Из чистой копии коммита выполните `python3 scripts/updates.py validate v1.7.0`
  и `python3 -m unittest discover -s scripts -p 'test_*.py'`.
- В каталоге плагина выполните `npm ci --include=dev`, `npm run typecheck`
  и `bb plugin build .`.
- Проверьте состав файлов относительно `v1.6.0` и выполните
  `python3 scripts/privacy_check.py --history`.
- На сервере с установленным плагином проверьте версию 0.1.0 и состояние
  `running` командой `bb plugin list --json`.
