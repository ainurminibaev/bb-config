## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `code-open-project-root` — Code Open 0.4.1 открывает основной checkout проекта

На сервере BB обновляет установленный Code Open до 0.4.1. Кнопка в заголовке
проекта открывает его основной checkout на машине источника по умолчанию.
В строке и шапке треда открывается окружение этого треда. Все три кнопки
открывают чат KodaForge для соответствующей области. Повтор сверяет версию.
Для отката собрать и перезагрузить предыдущую версию Code Open.

### `menubar-status-plan-prices` — Menubar Status 0.3.2: цены тарифов Pro Lite, Pro Max и Max в панели

Обновляет Menubar Status до 0.3.2. Панель в строке меню показывает ту же
цену тарифа, что и «Все аккаунты»: Codex Pro Lite $100, Pro $200,
Pro Max $500, Go $8; Claude Max 5x $100, Max 20x $200 (Max без множителя —
без цены). Таблица лежит в `macos/panel.html`, поэтому на каждом Mac с
установленной панелью после обновления плагина повтори `zsh macos/install.sh`
из закреплённой версии и проверь подпись тарифа в панели.

### `plugin-codex-goal-queue` — Codex Goal Queue 0.1.0: /goal resume в работающем треде Codex ждёт конца хода

### `plugin-codex-goal-queue` — /goal resume в работающем треде Codex ждёт конца хода

Выполняется на сервере BB, зависимостей нет. Новый необязательный компонент:
спросите пользователя, нужен ли он. Полезен тем, кто работает с целями Codex.

Встроенный провайдер Codex выполняет `/goal resume`, `/goal pause` и
`/goal clear` только когда сообщение начинает ход. Отправленная в работающий
ход, команда уходит модели текстом, и статус цели не меняется. Плагин отвечает
на штатный вопрос BB о каждом сообщении (`message.dispatch`) и действует только
для тредов Codex, только для сообщений человека и только когда сообщение попало
бы в работающий ход:

- `/goal resume` ставится в очередь треда с пометкой «Held by Codex Goal Queue ·
  выполнится сам после текущего хода Codex» и отправляется сам, когда тред
  освободится. Повтор, пока команда ждёт, отклоняется с пояснением.
- `/goal pause` и `/goal clear` отклоняются с пояснением, что сделать вместо
  этого: «Стоп» ставит активную цель на паузу, `bb thread clear-goal` очищает.

Остальные сообщения, другие провайдеры и сообщения от других тредов проходят
без изменений. Настроек, данных и команд у плагина нет.

Шаг уже применён, если `bb plugin list` показывает `codex-goal-queue` нужной
версии в состоянии running. Установка: в `plugins/codex-goal-queue` выполнить
`npm ci --include=dev`, `bb plugin build .`, `bb plugin install .`.

Проверка поведения: в тестовом треде Codex с целью на паузе во время
работающего хода отправить `/goal resume` — над полем ввода появляется карточка
очереди с пометкой плагина, после хода цель становится active. Работающие
треды установка не затрагивает; при повторе после прерывания начните с
`bb plugin list`.

Если установлено исправление самого провайдера
(`scripts/apply_codex_goal_steer.py --check` отвечает 0) или более новый BB уже
выполняет команды цели во время хода, плагин не нужен: он только задержит
команду до конца хода.

### `plugin-machine-tabs-pager-overlay` — Machine Tabs 0.2.7: строка «Показать ещё» ниже и мельче

На сервере BB обновляет Machine Tabs до 0.2.7. Строка «Показать ещё» под
длинными списками в боковой панели ужата до 14 px и мелкого шрифта, поэтому
место под неё больше не выглядит пустой полосой. Как и раньше, она проявляется
при наведении на список. Повтор сверяет версию. Откат — machine-tabs 0.2.6 из
релиза v1.10.0.

### `thread-account-usage-plan-labels` — Thread Account Usage 0.1.1 показывает фактический тариф

На сервере BB обновляет Thread Account Usage до 0.1.1. Тариф Claude берётся
из профиля аккаунта, который Claude Code обновляет в `.claude.json` на машине:
после перехода с Pro на Max карточка показывает «Max 20x $200» или
«Max 5x $100», а не «Pro $20» из старого входа. Тарифы Codex Pro Lite и
Pro Max подписаны отдельно ($100 и $500), Pro — $200, Go — $8.
Повтор сверяет версию. Для отката собрать и перезагрузить 0.1.0.
