# v1.19.0 — KodaForge: превью файлов, Finder и вкладки проектов

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **KodaForge переходит на форк** (`ainurminibaev/bb-plugin-kodaforge`, 0.7.101 =
  0.7.0 автора и правки, отправленные ему pull request'ами). Во вкладке редактора
  открываются картинки, видео, аудио, PDF, docx, xlsx, pptx, csv, Markdown и SVG
  (у текстовых — Source / Preview); в дереве — «Open in Terminal» и пункты других
  плагинов; «Close all» закрывает файлы, а не KodaForge; вкладки рабочих областей
  в шапке BB; по настройке — свои вкладки у каждого проекта. Настройки переносятся,
  при сбое возвращается каталожная версия. Новые версии автора Plugin Keeper
  отмечает раз в сутки.
- **KodaForge Inspector 0.3.3:** кнопка «Вид…» есть и в классическом виде.
- **Project Open 0.3.6:** «Открыть в Finder» / «Показать в Finder» из дерева
  KodaForge; машины и папки проектов обработчик на Mac берёт из BB, SSH-запись
  подбирает по ключу сервера; при обрыве сети отказывает за секунды; домашние
  папки целиком не открываются. Обработчик на Mac обновляется вручную (см. шаг).

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `kodaforge-fork` — KodaForge из форка: превью файлов, Markdown, терминал в папке, свои вкладки

Переводит KodaForge с каталога на форк
`ainurminibaev/bb-plugin-kodaforge` (версия 0.7.101 = 0.7.0 автора и правки из
`FORK.md`). Настройки плагина переносятся; открытые вкладки и раскладка лежат в
браузере и не меняются. Если форк не поднялся, каталожная версия возвращается сама.

Новое: картинки, видео, аудио, PDF, docx, xlsx, pptx, csv, Markdown и SVG
открываются во вкладке KodaForge (у текстовых есть кнопка Source / Preview); в
дереве — «Open in Terminal» и пункты других плагинов; «Close all» закрывает файлы,
а не KodaForge; настройка «Separate tabs per project» (выключена).
Project Open 0.3.2 добавляет в дерево «Открыть в Finder»; BB предлагает его сам.
Выделение файла — после обновления обработчика на Mac (`plugins/project-open/README.ru.md`).

Проверка: `python3 scripts/plugin_fork.py check kodaforge`; в KodaForge
открываются картинка и `.md`.

### `kodaforge-inspector-view-button` — KodaForge Inspector 0.3.3 — выбор вида из классического вида

Небольшая кнопка «Вид…» в шапке KodaForge есть и в классическом виде, и когда выбор
отложен. Нужна сборка KodaForge с местом в шапке (0.7.101 форка); без него вид меняется
в настройках плагина. Откат: тег kodaforge-inspector/v0.3.2.

### `project-open-auto-machines` — Project Open 0.3.6 — машины и папки для Finder из BB

Обработчик Finder сам узнаёт из BB машины и папки проектов, а SSH-запись подбирает
по ключу сервера. При обрыве сети он отказывает за секунды. Домашние папки целиком (`/root` и т. п.) Finder не открывает.

На каждом Mac, где уже стоит `BB Project Folder.app`, обновите обработчик до 0.4.1:
скопируйте три файла из `plugins/project-open/macos/` и выполните
`python3 install.py` (без `--config` прежний `config.json` сохраняется). macOS может
снова спросить доступ. Подключённый старый диск работает до отключения в Finder.
Откат: плагин — тег project-open/v0.3.2, обработчик — прежняя копия приложения.

## Проверка релиза

Из чистого клона коммита выпуска: `python3 scripts/updates.py validate v1.19.0`,
`python3 -m unittest discover -s scripts -p 'test_*.py'`, тесты `plugins/project-open`
(vitest) и `python3 plugins/voice-mode-keeper/test_patch_keeper.py`,
`python3 scripts/privacy_check.py --history`. На установке автора шаги проверены
режимом `development`; KodaForge 0.7.101, Inspector 0.3.3, Project Open 0.3.6 работают.
