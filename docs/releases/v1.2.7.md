# v1.2.7 — Уведомление только при доступном обновлении

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- «Обновить с ИИ» появляется в уведомлении о доступном релизе. Пункт
  «Обновления доработок BB» убран из нижнего ряда и меню «…».
- Версия, описание релиза и кнопка «Проверить сейчас» доступны в настройках
  Config Updates.

## Шаги

### `plugin-config-updates-notice` — Config Updates 0.1.7 — уведомление только при доступном релизе

Обновляет Config Updates на сервере BB. Действие «Обновить с ИИ» показывается
в уведомлении о доступном релизе. Ручная проверка и описание релиза доступны
в настройках плагина.

После шага откройте меню «…» нижнего ряда и раздел «Обновления доработок» в
настройках. В меню больше нет пункта установщика доработок, а в настройках
доступна кнопка «Проверить сейчас». При новом релизе уведомление открывает
штатный экран нового треда BB с закреплённым заданием.

## Проверка релиза

- Тесты Config Updates проверяют поиск релизов и открытие штатного экрана BB.
- Проверка интерфейса покрывает отсутствие пункта нижнего ряда, появление
  уведомления при доступном релизе и его закрытие после установки.
