# v1.27.0 — Каскад подписок 0.3.9: модель CLI вместо профиля больше не роняет ход

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Модель CLI вместо профиля каскада не роняет ход.** Если у треда каскада в модели оказалось имя
  модели CLI (например, BB подставил модель по умолчанию, пока список моделей каскада был
  недоступен), ход больше не отказывает «Профиль каскада не найден». Модель из таблицы ассоциаций —
  ход «только эта модель» на ступенях её провайдера; иначе прежний профиль треда; иначе «Авто».
  Подмену объясняет строка в ленте.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `subscriptions-cascade-0-3-9` — Каскад подписок 0.3.9 — модель CLI в модели треда не роняет ход «профиль не найден»

Если в модели треда каскада оказалась модель CLI (например, «gpt-6.2-sol» после переустановки) или удалённый профиль, ход больше не падает с «Профиль каскада не найден». Модель из таблицы моделей идёт на ступенях своего провайдера, иначе ход идёт по прежнему профилю треда, иначе по «Авто», и строка в ленте объясняет подмену. Отказ остаётся, только если включённых профилей нет.
Откат: тег agentcli-subscriptions-cascade/v0.3.8.
