# v1.2.4 — Доверие к проектам Codex в BB

Общий порядок — [docs/updates.md](../updates.md).

## Шаги

### `plugin-codex-project-trust` — Codex Project Trust — доверие к проекту из карточки треда

Устанавливает плагин Codex Project Trust на сервер BB. Нужен BB 0.50.1
или новее. Для подтверждения доверия на машине треда нужен Codex CLI
0.170.0 или новее.

Шаг проверяет установленный источник и версию. Если плагина ещё нет, он
ставится из стабильного Git-тега отдельного публичного репозитория. Проверка
подтверждает, что управляемая сборка v1 запущена, или учитывает явное отключение
пользователем. Установка из другого источника требует проверки владельцем.

Повтор проверяет текущую установку. Отключение плагина убирает карточку.
Пользователь подтверждает каждый путь отдельно в треде. Шаг обновления не
меняет доверие к проектам и настройки Codex.

## Что изменилось

В треде Codex появилась карточка доверия к проекту. Перед подтверждением она
показывает путь, машину и пользовательский файл Codex. Плагин обновляется
из своего [репозитория релизов](https://github.com/ainurminibaev/bb-codex-project-trust/releases).

## Проверка релиза

- На Tru запущена управляемая версия 1.0.0 из отдельного Git-тега.
- По реальному предупреждению BB нашёл тред, путь проекта и нужный профиль.
  Запись доверия и повторное чтение проверены на отдельном профиле Codex.
- Скрипт релиза повторно проверяет установленный плагин без переустановки.
