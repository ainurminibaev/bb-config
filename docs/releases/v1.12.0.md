# v1.12.0 — Limit Guard 0.9.1, Project Catalog 0.8.0, Machine Tabs 0.2.8, Open on Desktop, исправления безопасности

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- **Limit Guard 0.9.1.** Пороги по аккаунтам: настройка `accountRules`, по умолчанию `$200: 80/85` — подписки за $200 работают до 80% 5-часового и 85% недельного окна; остальные аккаунты как раньше. Сообщение о лимите больше не начинает новый ход у треда, остановленного лимитом. Продолжение ждёт самого позднего сброса среди исчерпанных окон; при медленном BB неприоритетный тред судит по недавним цифрам. Проверка на секреты при отправке снимка смотрит всю неотправленную историю.
- **Project Catalog 0.8.0.** Копия треда вливается только после `project_land` или архива треда; копия с игнорируемыми файлами, которых нет в основной папке, не удаляется; при сбое git или списка тредов ничего не трогается.
- **Machine Tabs 0.2.8**: подтреды в счётчиках, время работы, отметка на родителе.
- **Open on Desktop 0.3.0**: одно меню «открыть с помощью / поделиться / сохранить».
- Исправления безопасности: Browser Page, Menubar Status, Plugin Keeper.


### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `file-local-open-apps-menu` — Open on Desktop 0.3.0: одно меню (правый клик) — открыть с помощью, поделиться, сохранить; HTML через локальный сервер

На сервере BB обновляет Open on Desktop до 0.3.0. Вместо трёх значков у ссылок
на файлы — один значок и правый клик по ссылке с общим меню: открыть на
компьютере, «Открыть с помощью» (приложения Mac для этого типа с иконками,
отсортированные по смыслу), «Поделиться» (скопировать файл в буфер обмена Mac,
путь, имя), сохранить в Загрузки и переход в штатное меню BB. HTML в браузере
открывается с локального сервера на Mac (127.0.0.1), поэтому работают скрипты,
модули и fetch(); переносятся и ресурсы, которые загружают скрипты, а битые
ссылки больше не ломают открытие. На Windows открывается приложение по
умолчанию. Повтор сверяет версию. Откат — file-local-open 0.2.0 из релиза v1.11.0.

### `limit-guard-account-thresholds` — Limit Guard 0.9.1: пороги по аккаунтам — подписки за $200 работают до 80% / 85%; сообщение о лимите не начинает ход

На сервере BB обновляет Limit Guard до 0.9.1. Новая настройка «Пороги по
аккаунтам» (`accountRules`), по умолчанию `$200: 80/85`: на подписках за $200
(Claude Max 20x, ChatGPT Pro) экономный режим и проверка темпа включаются не
раньше 80% 5-часового и 85% недельного окна, неприоритетные треды ниже этого не
ждут. Остальные аккаунты — как раньше. Тариф Claude читается из `~/.claude.json`
машины. Своё значение пользователя сохраняется. Повтор сверяет версию. Откат —
limit-guard 0.8.2 или пустое значение `accountRules`.

Заодно: сообщение `[limit-guard]` уходит только в идущий ход и больше не
начинает новый у треда, остановленного лимитом; продолжение при нескольких
исчерпанных окнах ждёт самого позднего сброса; при недоступном сервере BB
неприоритетный тред судит по цифрам не старше часа, а не пропускается.

### `plugin-machine-tabs-subthread-states` — Machine Tabs 0.2.8: подтреды в счётчиках, время хода, метка ↳ у родителя

На сервере BB обновляет Machine Tabs до 0.2.8. В меню проектов чипы считают
треды всех уровней, строки проектов отделяют главные треды от подтредов (метка
`↳`), у работающих тредов видно, сколько идёт текущий ход, а кнопка подтредов
показывает, что происходит внутри. В боковой панели у родителя с незавершёнными
подтредами — тусклая метка `↳⟳1` / `↳✕2`. Повтор сверяет версию.

### `project-catalog-safe-landing` — Project Catalog 0.8.0: копия треда вливается только по project_land или после архива, без потери файлов

На сервере BB обновляет Project Catalog до 0.8.0. Отдельная копия треда
вливается в основную папку только после `project_land` этого треда или когда
тред в архиве; между ходами копия и недоделанные коммиты остаются. Копия не
удаляется, если в ней есть игнорируемые файлы, которых нет в основной папке
(например `.local/`); папки сборки и зависимостей не мешают. При сбое списка
тредов или git ничего не трогается; ветка удаляется только когда она уже в
основной ветке. Повтор сверяет версию. Откат — project-catalog 0.7.0.

### `security-audit-browser-page-state-dir` — Browser Page 0.1.1: состояние bb-page в личном каталоге пользователя

На сервере BB обновляет Browser Page до 0.1.1. Скрипт навыка bb-page хранит
адрес DevTools и файл подключения в каталоге `<tmp>/bb-page-<uid>` и отказывается
работать, если каталог принадлежит другому пользователю или открыт для других.
Состояние прежнего каталога `<tmp>/bb-page` не используется: открытые вкладки
нужно открыть заново командой `open`. Откат — browser-page 0.1.0 из релиза v1.11.0.

### `security-audit-keeper-notice-version` — Plugin Keeper 0.2.11: в уведомление агенту попадает только обычная версия

На сервере BB обновляет Plugin Keeper до 0.2.11. Когда автор плагина сам
исправил то, что чинила наша правка, Keeper сообщает об этом в тред. Теперь в
это сообщение попадает только обычная версия вида X.Y.Z; любой другой текст
из манифеста автора в тред агента не передаётся. Повтор сверяет версию.
Откат — voice-mode-keeper 0.2.10 из релиза v1.11.0.

### `security-audit-limit-guard-history` — Limit Guard 0.8.2: проверка на секреты смотрит всю историю, которую отправляет снимок

На сервере BB обновляет Limit Guard до 0.8.2. При режиме snapshots=push-private
перед отправкой снимка в приватный репозиторий проверяются все версии файлов во
всех коммитах, которых ещё нет на origin (раньше — только итоговая разница). Если
секрет остался в предыдущем локальном снимке, отправляется снимок без этой
цепочки; если секрет есть в неотправленных коммитах ветки, снимок остаётся только
на машине. Повтор сверяет версию. Откат — limit-guard 0.8.1 из релиза v1.11.0.

### `security-audit-menubar-panel-threads` — Menubar Status 0.3.3: панель отвечает только в показанные ей треды

На сервере BB обновляет Menubar Status до 0.3.3. Запросы панели (ответ, открыть
тред) выполняются только для тредов, которые сейчас показаны в панели; запрос к
другому треду попадает в errors.json. Помощник на Mac сравнивает токен за
постоянное время — это вступит в силу после повторной установки помощника
(`macos/install.sh`), без неё всё работает как раньше. Откат — menubar-status
0.3.2 из релиза v1.11.0.
