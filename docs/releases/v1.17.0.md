# v1.17.0 — Один значок ошибки у подтреда

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Плагин Subthread Error Mark снят: в строке подтреда с ошибкой стояло два красных
  ⊗ — его и Machine Tabs (с 0.2.16 Machine Tabs отмечает такие подтреды сам).
- Новый `scripts/plugin_retire.py` и список `config/retired-plugins.json` для снятия
  плагинов, которые bb-config больше не поставляет.

## Шаги

### `bundle` — Полный набор компонентов bb-config

Выполняется первым. Сводит установку к заявленному набору `config/bundle.json` этого релиза: ставит отсутствующие компоненты, обновляет устаревшие (собственные плагины — из закреплённого коммита, форки и каталоговые — штатным `bb plugin install`/`update`), проверяет и чинит их настройку (например, мост Voice Mode). Исключённые пользователем компоненты не ставятся, отключённые остаются отключёнными, плагины из другого источника не заменяются. Личные входы, настройки и действия на других машинах перечисляются в отчёте (`attention`). Затем шаги пропущенных релизов проверяются по уже сведённому состоянию.

### `retire-subthread-error-mark` — Убрать Subthread Error Mark: второй красный ⊗ у подтреда с ошибкой

Удаляет плагин Subthread Error Mark. Machine Tabs (с 0.2.16) сам ставит красный ⊗
на тред с ошибкой, который BB не отмечает, в том числе на подтред, — в строке было
два одинаковых значка. После обновления остаётся один.

Плагин удаляется, только если Machine Tabs 0.2.16 или новее установлен и включён;
иначе шаг пропускается и плагин остаётся — без него ошибка подтреда была бы не видна.
Обновить Machine Tabs — Settings → Updates (`bb plugin update machine-tabs`), затем
повторить обновление.

Проверка: `python3 scripts/plugin_retire.py check subthread-error-mark`; у подтреда с
ошибкой в боковой панели один ⊗.
